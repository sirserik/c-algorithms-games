# Алгоритмы и игры на Си

Учебник для абсолютных новичков: учимся программировать на языке Си,
разбирая классические алгоритмы и собирая консольные игры. Каждая
строка кода объясняется; программу строим с нуля, шаг за шагом, и
смотрим результат после каждого шага.

## Что внутри

- **Основы** — установка компилятора, первая программа, минимум Си,
  массивы, строки, указатели и память.
- **Алгоритмы** — числовые задачи, НОД Евклида, простые числа и решето
  Эратосфена, алгоритмы над массивами, линейный и бинарный поиск,
  сортировки, рекурсия (Фибоначчи, Ханойские башни), строковые
  алгоритмы, динамические структуры данных.
- **Игры** — «Угадай число», камень-ножницы-бумага, виселица,
  крестики-нолики, сапёр, змейка.

## Структура

- `docs/tutorial/*.md` — главы учебника.
- `code/*.c` — итоговые программы каждой главы (компилируемые).
- `build/build-pdf.sh` — сборка PDF (pandoc + xelatex).
- `build/check-code.sh` — компиляция всех примеров с `-Wall -Wextra`.
- `build/STYLE_GUIDE.md` — правила написания глав.

## Сборка

```bash
./build/build-pdf.sh          # → Algoritmy-i-igry-na-Si.pdf
./build/check-code.sh         # проверить, что весь код собирается
```

Требуется: `clang`/`gcc`, `pandoc`, `xelatex` (MacTeX/TeX Live).
