# Глава 2. Минимум Си: переменные, ввод, ветвления, циклы, функции

Эта глава — фундамент. Мы возьмём наш «Привет, мир!» и будем
наращивать его, пока не получим маленькую интерактивную программу.
По дороге разберём всё, без чего не написать ни одного алгоритма:
**переменные и типы**, **вывод чисел**, **ввод с клавиатуры**,
**арифметику**, **ветвления** (`if`/`else`), **циклы** (`while`,
`for`) и **свои функции**.

Глава длинная, но это единственная теоретическая глава такого объёма.
Дальше будет в основном практика.

## Шаг 1. Переменная — коробка для значения

Программе нужно где-то хранить данные: число, которое ввёл
пользователь, промежуточный результат, счётчик. Для этого есть
**переменные**.

Переменная — это **именованная коробочка в памяти**, в которой лежит
значение. У коробочки есть имя (чтобы к ней обращаться) и тип (чтобы
знать, что в ней лежит и сколько места занимает).

```c
#include <stdio.h>

int main(void)
{
    int age = 25;
    printf("Возраст: %d\n", age);
    return 0;
}
```

Разбор новых вещей:

- `int age = 25;` — мы **объявили** переменную. По частям:
  - `int` — тип: целое число (мы его уже видели у `main`).
  - `age` — имя переменной. Имена пишем латиницей, можно буквы,
    цифры (не первой) и `_`. Регистр важен: `age` и `Age` — разные.
  - `=` — оператор **присваивания**: «положи в коробку `age`
    значение справа». Это **не** «равно» из математики! Это команда
    «запиши». Запомни сразу: один `=` — присвоить, два `==` —
    сравнить (про сравнение чуть позже).
  - `25` — само значение.
  - `;` — конец инструкции.
- `printf("Возраст: %d\n", age);` — здесь появилось кое-что новое:
  - `%d` внутри строки — это **спецификатор формата**. Он означает
    «сюда подставь целое число в десятичной записи» (`d` — *decimal*).
    `printf` увидит `%d` и возьмёт следующий аргумент.
  - после строки, через запятую, мы передали `age`. Его значение и
    встанет на место `%d`.

Скомпилируй и запусти — увидишь `Возраст: 25`.

### Основные типы

Пока хватит четырёх типов:

- `int` — целое число (например, −7, 0, 42). Обычно занимает 4 байта,
  вмещает примерно от −2 до +2 миллиардов.
- `double` — дробное число (3.14, −0.5). «Double» — двойная точность.
- `char` — один символ (`'A'`, `'?'`). Внутри это маленькое целое
  (код символа), занимает 1 байт.
- (`float` — тоже дробное, но менее точное; мы будем брать `double`.)

У каждого типа — свой спецификатор в `printf`:

```c
int    x = 42;     printf("%d\n", x);     // целое
double y = 3.14;   printf("%f\n", y);     // дробное
char   c = 'A';    printf("%c\n", c);     // символ
```

- `%d` — целое.
- `%f` — дробное (по умолчанию 6 знаков после запятой). Можно задать
  точность: `%.2f` напечатает два знака — `3.14`.
- `%c` — один символ.
- Заметь: `//` — это **комментарий**. Всё от `//` до конца строки
  компилятор игнорирует, это пометка для человека. Есть и
  многострочный вид: `/* ... */`.

## Шаг 2. Спрашиваем у пользователя — `scanf`

Программа интереснее, когда реагирует на ввод. Считать число с
клавиатуры умеет функция `scanf` (*scan formatted* — чтение с
форматированием), тоже из `stdio.h`.

```c
#include <stdio.h>

int main(void)
{
    int age;
    printf("Сколько тебе лет? ");
    scanf("%d", &age);
    printf("Через год будет %d\n", age + 1);
    return 0;
}
```

Что нового:

- `int age;` — объявили переменную **без** начального значения. Пока
  в ней «мусор» — случайное содержимое памяти. Мы сейчас его заполним
  вводом.
- `scanf("%d", &age);` — читаем целое число и кладём в `age`:
  - `"%d"` — формат: «ожидаю целое число».
  - `&age` — а вот это важно. Знак `&` означает «**адрес** переменной
    `age`», то есть «где в памяти лежит коробка `age`». `scanf` нужно
    не значение, а место, **куда** записать прочитанное. Поэтому
    передаём адрес.
  - **Самая частая ошибка новичка** — забыть `&` и написать
    `scanf("%d", age)`. Компилятор предупредит, а программа, скорее
    всего, упадёт. Правило простое: в `scanf` перед обычной
    переменной почти всегда стоит `&`.
- `age + 1` — арифметика прямо в аргументе `printf`. Сначала
  посчитается `age + 1`, потом результат подставится в `%d`.

Запуск:

```text
Сколько тебе лет? 25
Через год будет 26
```

### Арифметика

Операторы как в математике:

- `+` сложение, `-` вычитание, `*` умножение, `/` деление,
  `%` остаток от деления.

Две ловушки, о которые спотыкаются все:

**Целочисленное деление.** Если оба числа целые, `/` делит нацело,
дробную часть отбрасывает:

```c
printf("%d\n", 7 / 2);   // напечатает 3, а не 3.5
printf("%d\n", 7 % 2);   // напечатает 1 — остаток
```

Чтобы получить дробный результат, хотя бы одно число должно быть
дробным: `7.0 / 2` даст `3.5`.

**Остаток `%` очень полезен.** `n % 2` равно 0, если `n` чётное, и 1,
если нечётное. Это пригодится постоянно.

## Шаг 3. Принимаем решения — `if` и `else`

Программа должна уметь выбирать путь: «если число чётное — сделай так,
иначе — эдак». Для этого есть `if` (англ. «если»).

```c
#include <stdio.h>

int main(void)
{
    int n;
    printf("Введи число: ");
    scanf("%d", &n);

    if (n % 2 == 0) {
        printf("%d — чётное\n", n);
    } else {
        printf("%d — нечётное\n", n);
    }
    return 0;
}
```

Разбор:

- `if (условие) { ... }` — если условие истинно, выполняется блок в
  фигурных скобках. Условие пишут в круглых скобках.
- `n % 2 == 0` — условие. Здесь сразу два важных оператора:
  - `n % 2` — остаток от деления на 2.
  - `==` — оператор **сравнения** «равно». Возвращает «истину», если
    левая и правая части равны. Ещё раз: `==` сравнивает, `=`
    присваивает.
    Путаница между ними — классический баг. Если случайно написать
    `if (n = 0)`, компилятор с `-Wall` предупредит.
- `else { ... }` — «иначе». Выполняется, если условие `if` оказалось
  ложным. `else` не обязателен.

### Операторы сравнения и логики

Сравнения дают «истину» или «ложь»:

- `==` равно, `!=` не равно;
- `<` меньше, `>` больше, `<=` меньше или равно, `>=` больше или равно.

В Си нет отдельного типа «логическое» в классическом смысле: **ложь —
это 0, истина — любое ненулевое число** (обычно 1). Это пригодится.

Условия можно соединять:

- `&&` — «И» (оба условия истинны): `if (age >= 18 && age < 65)`.
- `||` — «ИЛИ» (хотя бы одно истинно): `if (c == 'y' || c == 'Y')`.
- `!` — «НЕ» (переворачивает): `if (!found)`.

Если веток несколько, их сцепляют через `else if`:

```c
if (n > 0) {
    printf("положительное\n");
} else if (n < 0) {
    printf("отрицательное\n");
} else {
    printf("ноль\n");
}
```

## Шаг 4. Повторяем — цикл `while`

Часто нужно повторить действие много раз. Самый понятный цикл —
`while` (англ. «пока»): «пока условие истинно — повторяй тело».

Напечатаем числа от 1 до 5:

```c
int i = 1;
while (i <= 5) {
    printf("%d ", i);
    i = i + 1;
}
printf("\n");
```

Разбор:

- `int i = 1;` — заводим **счётчик** и ставим в 1.
- `while (i <= 5)` — пока `i` не больше 5, выполняй тело.
- внутри печатаем `i` и пробел.
- `i = i + 1;` — увеличиваем счётчик на 1. **Без этой строки условие
  никогда не станет ложным, и программа зациклится навсегда** — это
  называется бесконечный цикл. Если такое случилось, останови
  программу клавишами Ctrl+C.

Вывод: `1 2 3 4 5`.

### Сокращения, которые ты будешь видеть всюду

`i = i + 1` пишут короче: `i++` (увеличить на 1) или `i += 1`.
Аналогично `i--` (уменьшить), `i += 3` (прибавить 3), `i *= 2`
(умножить на 2). Это просто более краткая запись того же самого.

## Шаг 5. Цикл `for` — когда знаем число повторений

Когда у цикла есть счётчик с понятным началом, концом и шагом, удобнее
`for`. Тот же вывод 1..5:

```c
for (int i = 1; i <= 5; i++) {
    printf("%d ", i);
}
printf("\n");
```

В скобках `for` — три части через `;`:

1. `int i = 1` — **инициализация**: выполняется один раз в начале.
2. `i <= 5` — **условие**: проверяется перед каждым повтором; пока
   истинно — цикл идёт.
3. `i++` — **шаг**: выполняется в конце каждого повтора.

Это ровно то же, что `while` выше, только всё про счётчик собрано в
одном месте. `for` — самый частый цикл в книге.

## Шаг 6. Свои функции

`printf` и `scanf` — чужие функции. Но мы можем писать **свои** — чтобы
не повторять код и дать кускам логики понятные имена.

Напишем функцию, которая возводит число в квадрат:

```c
#include <stdio.h>

int square(int x)
{
    return x * x;
}

int main(void)
{
    int n = 6;
    printf("%d в квадрате = %d\n", n, square(n));
    return 0;
}
```

Разбор `int square(int x)`:

- `int` (первый) — тип того, что функция **вернёт**. Здесь целое.
- `square` — имя функции, придумали сами.
- `(int x)` — **параметр**: функция принимает одно целое число и
  внутри называет его `x`. Параметры — это «вход» функции.
- `return x * x;` — посчитать `x * x` и **вернуть** наружу.

В `main` мы пишем `square(n)` — это **вызов**: передаём `n`, получаем
обратно результат, который тут же подставляется в `printf`.

Важный момент: функцию нужно объявить **до** того места, где её
вызывают. Поэтому `square` стоит выше `main`. (Есть способ объявить
функцию заранее, а тело написать ниже, — про это в главах с
алгоритмами.)

Функция, которая ничего не возвращает, имеет тип `void`:

```c
void hello(void)
{
    printf("Привет!\n");
}
```

`void` как тип результата = «ничего не возвращаю». Внутри такой
функции `return;` можно писать без значения (или не писать вовсе).

## Складываем всё вместе

Маленькая программа, использующая всё из этой главы: спрашивает число
и печатает его таблицу умножения, отмечая чётные строки.

```c
#include <stdio.h>

int is_even(int x)
{
    return x % 2 == 0;
}

int main(void)
{
    int n;
    printf("Таблица умножения для какого числа? ");
    scanf("%d", &n);

    for (int i = 1; i <= 10; i++) {
        int result = n * i;
        if (is_even(result)) {
            printf("%2d x %2d = %3d  (чётное)\n", n, i, result);
        } else {
            printf("%2d x %2d = %3d\n", n, i, result);
        }
    }
    return 0;
}
```

Новое здесь только оформление: `%2d` и `%3d` — это `%d` с указанием
**минимальной ширины** поля (2 и 3 знака). Числа выровняются в
столбик, таблица станет аккуратной.

Функция `is_even` возвращает результат сравнения `x % 2 == 0` —
помнишь, истина это 1, ложь это 0? Значит, `is_even` возвращает 1 для
чётных и 0 для нечётных, и `if (is_even(result))` срабатывает именно
на чётных.

Запуск:

```text
Таблица умножения для какого числа? 4
 4 x  1 =   4  (чётное)
 4 x  2 =   8  (чётное)
 4 x  3 =  12  (чётное)
...
```

(Для 4 все строки чётные — попробуй 3, увидишь чередование.)

Сохрани эту программу как `code/02-multiplication.c`.

## Частые ошибки

**`=` вместо `==` в условии.** `if (n = 5)` всегда «истина» и
испортит `n`. Нужно `if (n == 5)`. Компилятор с `-Wall` предупреждает.

**Забытый `&` в `scanf`.** `scanf("%d", n)` — почти всегда падение.
Правильно `scanf("%d", &n)`.

**Неверный спецификатор.** Печатать `double` через `%d` или `int`
через `%f` — мусор на экране. Тип и спецификатор должны совпадать.

**Бесконечный цикл.** Забыл менять счётчик в `while` — программа
висит. Ctrl+C, и добавь `i++`.

**Целочисленное деление врасплох.** `double avg = sum / count;` где
`sum` и `count` целые — деление произойдёт нацело **до** записи в
`double`. Приведи к дробному: `(double)sum / count`.

## Упражнения

1. Программа спрашивает два числа и печатает их сумму, разность,
   произведение и частное (частное — дробное, через `%.2f`).
2. Программа спрашивает число и говорит, положительное оно,
   отрицательное или ноль (через `if`/`else if`/`else`).
3. С помощью `for` напечатай все чётные числа от 2 до 20.
4. Напиши функцию `int max2(int a, int b)`, возвращающую большее из
   двух чисел, и проверь её в `main`.
5. Цикл `while`: спрашивай числа, пока пользователь не введёт 0, и в
   конце напечатай их сумму.
