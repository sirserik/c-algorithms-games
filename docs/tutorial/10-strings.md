# Глава 10. Строковые алгоритмы: длина, переворот, палиндром, слова, анаграммы

Строка — это просто массив символов с меткой конца `'\0'` (мы разобрали
это в главе 3). А раз так, над строкой можно гонять циклы и считать
что угодно: длину, число слов, проверять симметрию, сравнивать состав.
В этой главе мы напишем четыре маленьких, но настоящих строковых
алгоритма и поймём, как они устроены изнутри — не вызывая готовых
функций, а собирая логику руками.

## Важное предупреждение про русские буквы

Мы будем считать **символы** по одному. И тут есть ловушка. В кодировке
UTF-8 (так хранят текст современные системы) латинская буква и цифра
занимают **1 байт**, а русская буква — **2 байта**. Для программы на Си
строка — это байты. Поэтому если ты введёшь «привет», программа увидит
не 6 символов, а 12 байт, и посимвольные алгоритмы (переворот,
палиндром) дадут кашу: половинки букв перемешаются.

Вывод простой: **в этой главе вводим только латиницу, цифры и пробелы**.
Русский текст годится для сообщений (`printf` печатает байты как есть),
но не для посимвольной обработки. Полноценная работа с Юникодом —
отдельная большая тема, она за рамками книги.

## Что мы сделаем

Четыре программы, каждая в своём файле:

- `10-reverse.c` — своя функция длины строки и переворот строки на месте.
- `10-palindrome.c` — проверка, читается ли слово одинаково с двух концов.
- `10-words.c` — подсчёт слов во фразе.
- `10-anagram.c` — проверка, состоят ли два слова из одних и тех же букв.

Ничего нового из синтаксиса тут почти нет — только массивы, циклы,
`if` и `char`. Вся соль в **идеях алгоритмов**.

## Часть 1. Длина и переворот строки

### Разбираем задачу руками

Возьмём слово `hello`. Перевернуть его — значит получить `olleh`.
Как это сделать «на бумаге»? Поставим палец слева (на `h`) и палец
справа (на `o`) и **поменяем их местами**:

```
h e l l o      o e l l h      o l l e h
^       ^   ->    ^   ^    ->     ^^
```

Потом сдвигаем оба пальца к центру и снова меняем. Когда пальцы
встретились (или перекрестились) — всё, строка перевёрнута. Этот приём
— **два индекса с концов** — мы будем использовать постоянно.

Но прежде чем переворачивать, надо знать **длину** строки: где правый
край. Длину мы могли бы взять из `strlen`, но давай напишем свою — так
ты раз и навсегда поймёшь, как Си «видит» конец строки.

### Шаг 1. Своя функция длины

Строка заканчивается невидимым символом `'\0'` (нулевой байт). Значит,
длина — это сколько символов лежит **до** него. Идём циклом, пока не
упрёмся в `'\0'`, и считаем шаги:

```c
int my_strlen(const char *s)
{
    int len = 0;
    while (s[len] != '\0') {
        len++;
    }
    return len;
}
```

Разбор:

- `const char *s` — параметр-строка. `char *` — указатель на символы,
  то есть адрес начала строки (вспомни главу 3: имя массива — это
  адрес его первого элемента). Слово `const` — обещание «я эту строку
  менять не буду», только читаю. Компилятор за этим проследит.
- `s[len]` — `len`-й символ строки. К указателю на символы можно
  обращаться по индексу точно как к массиву.
- `while (s[len] != '\0')` — крутимся, **пока** текущий символ не
  нулевой. `!=` — «не равно». `'\0'` в одинарных кавычках — это один
  символ с кодом 0, метка конца строки.
- На каждом шаге `len++` — продвигаемся дальше. Когда `s[len]`
  окажется `'\0'`, цикл встанет, а в `len` будет ровно число символов
  до него. Его и возвращаем.

Сам `'\0'` в длину **не входит** — мы останавливаемся на нём, не
посчитав. Так же работает и настоящий `strlen` из `<string.h>`.

### Шаг 2. Наивный переворот (и где он спотыкается)

Прочитаем строку через `fgets` и сразу попробуем перевернуть. Наивная
мысль новичка: «пройду слева направо и буду переставлять символы».
Запишем переворот двумя индексами с концов — это и есть правильный
приём, но сначала запустим как есть и посмотрим на сюрприз:

```c
#include <stdio.h>

int my_strlen(const char *s)
{
    int len = 0;
    while (s[len] != '\0') {
        len++;
    }
    return len;
}

int main(void)
{
    char line[100];
    printf("Введи строку (латиницей): ");
    fgets(line, sizeof line, stdin);

    int len = my_strlen(line);

    int i = 0, j = len - 1;
    while (i < j) {
        char tmp = line[i];
        line[i] = line[j];
        line[j] = tmp;
        i++;
        j--;
    }

    printf("Перевёрнутая: %s\n", line);
    return 0;
}
```

Вводим `hello`, запускаем:

```text
Введи строку (латиницей): hello
Перевёрнутая: 
olleh
```

Перевёрнутое слово на месте, но откуда **лишний перенос строки**?
Почему `olleh` уехало на новую строку?

### Шаг 3. Виноват `'\n'` от fgets — убираем его

Когда ты нажимаешь Enter, в строку попадает символ перевода строки
`'\n'`, и `fgets` его **не выбрасывает**. То есть в `line` лежит не
`hello`, а `hello\n` — шесть символов. `my_strlen` честно вернул 6, и
наш переворот поставил `'\n'` в самое начало: получилось `\nolleh`.
Вот откуда пустая строка перед результатом.

Лечится это всегда одинаково: после `fgets` смотрим на последний
символ, и если это `'\n'` — затираем его на `'\0'`:

```c
int len = my_strlen(line);
if (len > 0 && line[len - 1] == '\n') {
    line[len - 1] = '\0';   /* обрезали перевод строки */
    len--;                  /* и длина стала на 1 меньше */
}
```

- `len > 0` — защита от пустого ввода: если в строке вообще ничего нет,
  не лезем в `line[-1]`.
- `line[len - 1]` — последний реальный символ (индексы с нуля, поэтому
  последний — это `len - 1`).
- `line[len - 1] = '\0';` — ставим метку конца на место `'\n'`. Теперь
  для всех функций строка кончается раньше, а `'\n'` как бы исчез.
- `len--` — длина уменьшилась на единицу, дальше работаем с ней.

Этот кусочек (обрезать `'\n'`) тебе понадобится после **каждого**
`fgets`. Запомни его как рефлекс.

### Полная программа: `10-reverse.c`

```c
#include <stdio.h>

/* Своя длина строки: считаем символы до '\0'. */
int my_strlen(const char *s)
{
    int len = 0;
    while (s[len] != '\0') {
        len++;
    }
    return len;
}

int main(void)
{
    char line[100];

    printf("Введи строку (латиницей): ");
    if (fgets(line, sizeof line, stdin) == NULL) {
        return 0;                       /* ввода не было */
    }

    /* Убираем хвостовой '\n', который оставил fgets. */
    int len = my_strlen(line);
    if (len > 0 && line[len - 1] == '\n') {
        line[len - 1] = '\0';
        len--;
    }

    /* Переворот на месте: меняем местами края, идём к центру. */
    int i = 0;
    int j = len - 1;
    while (i < j) {
        char tmp = line[i];
        line[i] = line[j];
        line[j] = tmp;
        i++;
        j--;
    }

    printf("Длина: %d\n", len);
    printf("Перевёрнутая: %s\n", line);
    return 0;
}
```

Что добавилось по сравнению с наивной версией:

- `if (fgets(...) == NULL)` — `fgets` возвращает `NULL`, если читать
  было нечего (например, ввод закрыли). Тогда просто выходим. Полезная
  привычка — проверять результат ввода.
- Блок обрезки `'\n'` — разобрали выше.
- `char tmp` — временная коробка для обмена. Чтобы поменять два
  значения местами, одно надо где-то придержать, иначе затрёшь. Это
  тот же приём `swap`, что в главе 3, только для символов.
- `while (i < j)` — крутимся, пока левый индекс левее правого. Как
  только они встретились в центре (`i == j`) или разошлись — конец.
  Средний символ (если длина нечётная) остаётся на месте, и правильно:
  его двигать некуда.

Проверяем:

```text
$ cc -std=c11 -Wall -Wextra -O2 10-reverse.c -o 10-reverse
$ ./10-reverse
Введи строку (латиницей): hello
Длина: 5
Перевёрнутая: olleh
```

Лишнего переноса больше нет — `'\n'` мы убрали.

## Часть 2. Палиндром

**Палиндром** — слово, которое читается одинаково слева направо и
справа налево: `level`, `radar`, `noon`. А `world` — не палиндром.

### Идея

Тот же приём двух индексов, что и в перевороте, только теперь мы ничего
не меняем, а **сравниваем**. Левый символ должен совпадать с правым,
второй слева — со вторым справа, и так до центра. Нашли хоть одно
несовпадение — это не палиндром, дальше можно не проверять.

Заведём флаг `is_palindrome`, поставим его в `1` («да, палиндром») и
сбросим в `0`, если поймаем разные символы.

### Программа: `10-palindrome.c`

```c
#include <stdio.h>

int my_strlen(const char *s)
{
    int len = 0;
    while (s[len] != '\0') {
        len++;
    }
    return len;
}

int main(void)
{
    char line[100];

    printf("Введи слово (латиницей): ");
    if (fgets(line, sizeof line, stdin) == NULL) {
        return 0;
    }

    int len = my_strlen(line);
    if (len > 0 && line[len - 1] == '\n') {
        line[len - 1] = '\0';
        len--;
    }

    /* Два индекса идут навстречу друг другу. */
    int i = 0;
    int j = len - 1;
    int is_palindrome = 1;              /* пока считаем, что да */
    while (i < j) {
        if (line[i] != line[j]) {
            is_palindrome = 0;         /* нашли несовпадение */
            break;
        }
        i++;
        j--;
    }

    if (is_palindrome) {
        printf("\"%s\" — палиндром\n", line);
    } else {
        printf("\"%s\" — не палиндром\n", line);
    }
    return 0;
}
```

Разбор новых мест:

- `int is_palindrome = 1;` — **флаг**: переменная-да/нет. `1` — «истина»,
  `0` — «ложь» (в Си нет отдельного типа `bool` без подключения
  `<stdbool.h>`, поэтому просто берём `int`). Начинаем с оптимизма:
  считаем слово палиндромом, пока не доказано обратное.
- `if (line[i] != line[j])` — сравниваем края. Если символы разные —
  это уже не палиндром.
- `break;` — досрочно выходим из цикла. Раз нашли несовпадение, дальше
  проверять незачем — ответ уже известен. `break` обрывает ближайший
  цикл.
- `\"%s\"` — обратный слэш перед кавычкой говорит `printf`: «это
  обычная кавычка, печатай её», а не конец строки формата. Так слово в
  выводе берётся в кавычки.

Проверяем на двух словах:

```text
$ cc -std=c11 -Wall -Wextra -O2 10-palindrome.c -o 10-palindrome
$ ./10-palindrome
Введи слово (латиницей): level
"level" — палиндром
$ ./10-palindrome
Введи слово (латиницей): world
"world" — не палиндром
```

Пустая строка и строка из одного символа — палиндромы по определению,
и программа это учитывает: при `len <= 1` цикл `while (i < j)` ни разу
не выполнится, флаг останется `1`.

## Часть 3. Подсчёт слов

Посчитаем, сколько слов во фразе. Слова разделены пробелами, причём
пробелов между словами может быть **несколько**, и в начале/конце они
тоже бывают. Простое `считать пробелы и прибавить единицу` тут
сломается: `the   quick` (три пробела) дало бы лишние слова.

### Идея: ловим начало слова

Слово начинается там, где **за пробелом идёт буква**. Будем идти по
строке символ за символом и держать флаг `in_word` — «мы сейчас внутри
слова или нет». Логика:

- встретили пробел → мы вне слова (`in_word = 0`);
- встретили не-пробел и до этого были вне слова → это **начало нового
  слова**: прибавляем счётчик и помечаем `in_word = 1`;
- встретили не-пробел, но уже были внутри слова → ничего не делаем,
  просто продолжаем то же слово.

Так каждое слово считается ровно один раз — в момент его первой буквы.
Сколько бы пробелов ни стояло вокруг, лишних единиц не набежит.

### Программа: `10-words.c`

```c
#include <stdio.h>

int my_strlen(const char *s)
{
    int len = 0;
    while (s[len] != '\0') {
        len++;
    }
    return len;
}

int main(void)
{
    char line[200];

    printf("Введи фразу (латиницей): ");
    if (fgets(line, sizeof line, stdin) == NULL) {
        return 0;
    }

    int len = my_strlen(line);
    if (len > 0 && line[len - 1] == '\n') {
        line[len - 1] = '\0';
        len--;
    }

    int words = 0;
    int in_word = 0;                   /* сейчас мы внутри слова? */
    for (int i = 0; i < len; i++) {
        char c = line[i];
        if (c == ' ' || c == '\t') {
            in_word = 0;               /* пробел — слово кончилось */
        } else {
            if (in_word == 0) {        /* переход «пробел -> буква» */
                words++;               /* начало нового слова */
                in_word = 1;
            }
        }
    }

    printf("Слов: %d\n", words);
    return 0;
}
```

Разбор:

- `char c = line[i];` — для удобства кладём текущий символ в `c`, чтобы
  не писать `line[i]` четыре раза.
- `if (c == ' ' || c == '\t')` — проверяем, разделитель ли это. `' '` —
  обычный пробел, `'\t'` — табуляция. `||` — «или»: условие верно, если
  это пробел **или** таб.
- В ветке-разделителе сбрасываем `in_word = 0` — «мы вышли из слова».
- В ветке-не-разделителе смотрим: `if (in_word == 0)` — если мы только
  что были вне слова, значит это его первая буква. Прибавляем `words++`
  и ставим `in_word = 1`. Пока буквы идут подряд, `in_word` остаётся
  `1`, и счётчик не растёт — слово считается один раз.

Проверяем на фразе с кучей лишних пробелов и на пустом вводе:

```text
$ cc -std=c11 -Wall -Wextra -O2 10-words.c -o 10-words
$ ./10-words
Введи фразу (латиницей):   the   quick brown   fox  
Слов: 4
$ ./10-words
Введи фразу (латиницей): 
Слов: 0
```

Лишние пробелы по краям и между словами не помешали — флаг `in_word`
сделал своё дело.

## Часть 4. Анаграммы

**Анаграммы** — два слова из одних и тех же букв, переставленных в
другом порядке: `listen` и `silent`, `anagram` и `nagaram`. А `hello`
и `world` — нет.

### Идея: считаем частоты букв

Как проверить руками? Можно отсортировать буквы каждого слова и
сравнить. Но есть приём проще и быстрее — **подсчёт частот**.

Заведём на каждую возможную букву свой счётчик. Пройдём по первому
слову и для каждой буквы **прибавим** её счётчик. Потом пройдём по
второму слову и для каждой буквы **вычтем**. Если слова — анаграммы,
то каждую букву мы столько же раз прибавили, сколько вычли, и все
счётчики в конце окажутся **нулевыми**. Если где-то остался не ноль —
буквы не совпали по составу.

Под счётчики возьмём массив `int count[256]`. Почему 256? Символ
`char` в Си — это, по сути, маленькое целое число (код символа), и
один байт принимает значения от 0 до 255. Сделав массив на 256 ячеек,
мы заводим отдельный счётчик под **любой** возможный байт. Сам код
символа служит индексом: для буквы `a` (код 97) растёт `count[97]`.

### Программа: `10-anagram.c`

```c
#include <stdio.h>

int my_strlen(const char *s)
{
    int len = 0;
    while (s[len] != '\0') {
        len++;
    }
    return len;
}

/* Убирает хвостовой '\n' от fgets. */
void chomp(char *s)
{
    int len = my_strlen(s);
    if (len > 0 && s[len - 1] == '\n') {
        s[len - 1] = '\0';
    }
}

int main(void)
{
    char a[200];
    char b[200];

    printf("Первое слово (латиницей): ");
    if (fgets(a, sizeof a, stdin) == NULL) {
        return 0;
    }
    printf("Второе слово (латиницей): ");
    if (fgets(b, sizeof b, stdin) == NULL) {
        return 0;
    }

    chomp(a);
    chomp(b);

    /* По счётчику на каждый из 256 возможных байтов. */
    int count[256] = {0};

    for (int i = 0; a[i] != '\0'; i++) {
        count[(unsigned char)a[i]]++;  /* в первом слове — прибавляем */
    }
    for (int i = 0; b[i] != '\0'; i++) {
        count[(unsigned char)b[i]]--;  /* во втором — вычитаем */
    }

    /* Если все счётчики нулевые — буквы совпали по составу. */
    int anagram = 1;
    for (int k = 0; k < 256; k++) {
        if (count[k] != 0) {
            anagram = 0;
            break;
        }
    }

    if (anagram) {
        printf("\"%s\" и \"%s\" — анаграммы\n", a, b);
    } else {
        printf("\"%s\" и \"%s\" — не анаграммы\n", a, b);
    }
    return 0;
}
```

Разбор новых мест:

- `void chomp(char *s)` — мы вынесли обрезку `'\n'` в отдельную
  функцию, чтобы не дублировать её для `a` и `b`. `void` — функция
  ничего не возвращает, только меняет переданную строку (она получает
  её адрес, поэтому правки видны снаружи — см. главу 3).
- `int count[256] = {0};` — массив из 256 счётчиков. Запись `= {0}`
  заполняет **все** ячейки нулями. Это важно: без инициализации в
  массиве был бы мусор, и счёт сломался бы.
- `count[(unsigned char)a[i]]++` — берём код текущего символа и
  используем как индекс, увеличивая нужный счётчик.
- `(unsigned char)` — зачем приведение? Тип `char` может быть знаковым,
  и для байтов выше 127 (если вдруг затешется не-ASCII) код стал бы
  **отрицательным** — а это выход за границу массива (`count[-50]`).
  Приведение к `unsigned char` гарантирует диапазон 0..255. Привычка
  на будущее, чтобы не нарваться.
- Второй цикл с `--` — вычитаем частоты второго слова.
- Финальный цикл проверяет, что **все** счётчики обнулились. Нашли
  ненулевой — `anagram = 0` и `break`.

Проверяем:

```text
$ cc -std=c11 -Wall -Wextra -O2 10-anagram.c -o 10-anagram
$ ./10-anagram
Первое слово (латиницей): listen
Второе слово (латиницей): silent
"listen" и "silent" — анаграммы
$ ./10-anagram
Первое слово (латиницей): hello
Второе слово (латиницей): world
"hello" и "world" — не анаграммы
```

Этот приём — «массив-счётчик, где индекс это сам символ» — очень
мощный. Им же можно посчитать, сколько раз встречается каждая буква,
найти первый неповторяющийся символ и многое другое.

## Частые ошибки

**Забыли обрезать `'\n'` после `fgets`.** Самая частая беда этой главы.
Перевод строки портит и переворот (улетает в начало), и сравнение
(`"level\n"` уже не палиндром), и подсчёт. После каждого `fgets` —
обрезай.

**Сравнение строк через `==`.** Если захочешь сравнить две строки
целиком, `a == b` сравнит **адреса**, а не текст (см. главу 3). Для
содержимого нужен `strcmp` из `<string.h>`. В наших алгоритмах мы
сравниваем символы по одному (`line[i] != line[j]`) — вот так с
отдельными `char` через `==`/`!=` всё в порядке, это числа.

**Забыли `'\0'`.** Если будешь собирать строку вручную (например,
копировать символы в другой массив), не забудь поставить `'\0'` в
конце сам — иначе `printf("%s", ...)` напечатает мусор до первого
случайного нуля в памяти.

**Не обнулили массив-счётчик.** `int count[256];` без `= {0}` содержит
мусор, и подсчёт частот соврёт. Всегда инициализируй счётчики нулём.

**Кириллица в посимвольном алгоритме.** Введёшь русское слово — UTF-8
разложит его на пары байтов, и переворот/палиндром дадут бессмыслицу.
В этой главе — только латиница.

## Упражнения

1. Добавь в `10-reverse.c` подсчёт **гласных** (`a, e, i, o, u`) в
   введённой строке и выведи их число.
2. Перепиши проверку палиндрома так, чтобы она **игнорировала регистр**:
   `Level` тоже считался палиндромом. Подсказка: перед сравнением
   приводи символы к одному регистру (`'A'..'Z'` отличаются от
   `'a'..'z'` на постоянную величину — 32).
3. Сделай вариант подсчёта слов, который ещё и печатает **длину самого
   длинного слова** во фразе.
4. Напиши программу, которая печатает, **сколько раз** встречается
   каждая латинская буква во введённой строке (используй массив-счётчик
   из части 4, выводи только буквы с ненулевым счётчиком).
5. Проверка анаграмм игнорирует пробелы: сделай так, чтобы
   `dirty room` и `dormitory` считались анаграммами (пробелы при
   подсчёте просто пропускай).
6. Напиши функцию `int my_strcmp(const char *a, const char *b)`, которая
   возвращает 0, если строки равны, и не 0 иначе — своими руками,
   сравнивая символы в цикле, без `<string.h>`.

## Что мы получили

Теперь ты умеешь обрабатывать строки **изнутри**, не полагаясь на
готовые функции: считать длину циклом до `'\0'`, ходить по строке двумя
индексами с концов (переворот, палиндром), вести флаг состояния
(`in_word` при подсчёте слов) и применять массив-счётчик по коду
символа (анаграммы, частоты). И, что важно, ты знаешь главную ловушку —
хвостовой `'\n'` от `fgets` — и убираешь его на автомате.

Пока все наши данные жили в массивах фиксированного размера: `char
line[100]`, `int count[256]`. Но что, если заранее неизвестно, сколько
элементов понадобится, и они должны то добавляться, то удаляться?
Тогда массива мало. В следующей главе — **динамические структуры
данных**: мы соберём список, который растёт сам, связывая элементы
указателями. Тут и пригодятся `malloc`/`free` из главы 3.

Итоговые программы главы — `code/10-reverse.c`, `code/10-palindrome.c`,
`code/10-words.c`, `code/10-anagram.c`.
