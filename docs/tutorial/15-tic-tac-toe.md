# Глава 15. Игра «Крестики-нолики»

Пора собрать первую настоящую игру с полем. Крестики-нолики знают все:
поле 3×3, двое игроков по очереди ставят X и O, кто первым выстроит три
в ряд — выиграл. Если поле заполнилось, а ряда нет — ничья.

Игра простая на вид, но в ней есть всё, из чего состоят игры посложнее:
**двумерное поле** в памяти, **печать** этого поля на экран, **ввод
хода** с проверкой, **смена игрока** и **проверка условия победы**. Это
ровно тот набор, который мы переиспользуем в сапёре, морском бое и
дальше.

Главное новое в этой главе — **двумерный массив**. С ним и начнём.

## Что мы сделаем

Игру на двоих за одним компьютером. Программа:

- рисует поле 3×3 с номерами клеток-подсказок;
- спрашивает у игрока номер клетки (1–9);
- проверяет, что клетка существует и свободна;
- ставит фигуру, меняет игрока;
- после каждого хода проверяет победу (три в ряд) и ничью;
- объявляет результат и заканчивает партию.

Никаких новых библиотек не понадобится — только `stdio.h`, который ты
уже знаешь. Зато разберём двумерный массив, вложенные циклы и аккуратную
проверку ввода.

## Разбираем задачу руками

Возьми лист бумаги и нарисуй поле. Девять клеток. Пронумеруем их так:

```text
 1 | 2 | 3
---+---+---
 4 | 5 | 6
---+---+---
 7 | 8 | 9
```

Игрок X говорит «5» — ставим X в центр. Игрок O говорит «1» — ставим O в
левый верхний угол. И так далее. После каждого хода смотрим: не собрал
ли кто-то три своих знака в одну линию?

Линий всего восемь:

- три горизонтальные: {1,2,3}, {4,5,6}, {7,8,9};
- три вертикальные: {1,4,7}, {2,5,8}, {3,6,9};
- две диагонали: {1,5,9} и {3,5,7}.

Если в какой-то линии стоят три одинаковых знака — этот игрок победил.
Если все девять клеток заняты, а победителя нет — ничья.

Теперь главный вопрос: как хранить поле в памяти?

## Двумерный массив — таблица в памяти

Обычный массив — это ряд коробок:

```c
int a[5];        // a[0], a[1], a[2], a[3], a[4]
```

Но поле — не ряд, а **таблица**: 3 строки и 3 столбца. Для таблиц в Си
есть **двумерный массив** — массив, у которого **два** индекса:

```c
char board[3][3];
```

Читается так: «`board` — это 3 строки, в каждой по 3 ячейки типа
`char`». Всего 3 × 3 = 9 ячеек. Чтобы добраться до одной, нужны **два**
номера:

```c
board[row][col]
```

- первый индекс `row` (англ. *row* — строка) — **номер строки**, 0, 1
  или 2;
- второй индекс `col` (англ. *column* — столбец) — **номер столбца**, 0,
  1 или 2.

Как и у обычного массива, **нумерация с нуля**. Левая верхняя клетка —
это `board[0][0]`, правая нижняя — `board[2][2]`. Центр — `board[1][1]`.

Вот вся карта индексов:

```text
 board[0][0] | board[0][1] | board[0][2]
-------------+-------------+-------------
 board[1][0] | board[1][1] | board[1][2]
-------------+-------------+-------------
 board[2][0] | board[2][1] | board[2][2]
```

### Как это лежит в памяти

В памяти нет никаких «строк» и «столбцов» — там всё подряд, одной
лентой. Двумерный массив раскладывается **построчно**: сначала вся
строка 0, потом вся строка 1, потом строка 2.

```text
 [0][0] [0][1] [0][2] [1][0] [1][1] [1][2] [2][0] [2][1] [2][2]
```

Девять ячеек `char` подряд — это 9 байт. Запись `board[row][col]` —
просто удобный способ сказать компьютеру «отсчитай нужную ячейку в этой
ленте». Тебе про ленту думать не нужно: пиши два индекса, и всё.

### Перебор двумерного массива — цикл в цикле

Один индекс перебирают одним циклом `for`. Два индекса — **двумя
вложенными** циклами: внешний идёт по строкам, внутренний по столбцам.

```c
for (int row = 0; row < 3; row++) {
    for (int col = 0; col < 3; col++) {
        // здесь доступна клетка board[row][col]
    }
}
```

Как это работает по шагам: внешний цикл ставит `row = 0` и запускает
внутренний цикл целиком — `col` пробегает 0, 1, 2. Это вся первая
строка. Потом внешний цикл ставит `row = 1`, и внутренний снова крутится
0, 1, 2 — вторая строка. И так до `row = 2`. В сумме внутреннее тело
выполнится 3 × 3 = 9 раз, ровно по одному на каждую клетку. Этот приём
— основа работы с любым полем.

## Шаг 1. Рисуем пустое поле

Начнём с малого: завести поле, заполнить его цифрами-подсказками 1–9 и
напечатать. Цифры в пустых клетках удобны — игрок сразу видит, каким
числом назвать клетку.

```c
#include <stdio.h>

int main(void)
{
    char board[3][3];

    char digit = '1';
    for (int row = 0; row < 3; row++) {
        for (int col = 0; col < 3; col++) {
            board[row][col] = digit;
            digit++;
        }
    }

    for (int row = 0; row < 3; row++) {
        printf(" %c | %c | %c \n",
               board[row][0], board[row][1], board[row][2]);
    }
    return 0;
}
```

Разбор нового:

- `char board[3][3];` — наш двумерный массив на 9 символов. Тип `char`
  потому, что в клетке будет либо цифра-подсказка (`'1'`…`'9'`), либо
  фигура (`'X'` или `'O'`) — а это всё одиночные символы.
- `char digit = '1';` — заводим символ-счётчик и ставим его в `'1'`.
  Обрати внимание: это **символ** `'1'` в одинарных кавычках, а не
  число 1. Внутри `char` хранится код символа, и у соседних цифр коды
  идут подряд: за `'1'` следует `'2'`, за `'2'` — `'3'`. Поэтому…
- `digit++;` — увеличивает символ до следующего. После `'1'` получим
  `'2'`, и так до `'9'`. Тот же `++`, что и для чисел.
- `board[row][col] = digit;` — кладём текущую цифру в клетку. На первом
  обороте это `board[0][0] = '1'`, дальше `'2'`, `'3'` и т. д.
- В `printf(" %c | %c | %c \n", ...)` спецификатор `%c` печатает один
  символ (мы знаем его с главы 2). Три `%c` — три клетки одной строки,
  между ними рисуем разделитель `|`.

Запуск:

```text
 1 | 2 | 3
 4 | 5 | 6
 7 | 8 | 9
```

Поле есть. Но между строками нет горизонтальных линий — выглядит бедно.

## Шаг 2. Добавляем разделители и выносим печать в функцию

Печатать поле придётся после **каждого** хода. Копировать цикл печати по
всему коду — плохо: длинно и легко ошибиться. Вынесем печать в отдельную
функцию `print_board`, а заодно дорисуем горизонтальные линии.

```c
void print_board(char board[3][3])
{
    printf("\n");
    for (int row = 0; row < 3; row++) {
        printf(" %c | %c | %c \n",
               board[row][0], board[row][1], board[row][2]);
        if (row < 2) {
            printf("---+---+---\n");
        }
    }
    printf("\n");
}
```

Разбор:

- `void print_board(char board[3][3])` — функция, которая ничего не
  возвращает (`void`, см. главу 2), а принимает наше поле. Как передать
  двумерный массив в функцию? Указываем тип ровно так, как объявляли:
  `char board[3][3]`. Размеры в скобках важны — по ним функция знает,
  как раскладывать ленту памяти на строки.
  - Тонкость: массив (в том числе двумерный) передаётся в функцию **по
    адресу**, а не копией (см. главу 3 про указатели). Это значит, что
    функция работает с **тем же самым** полем, что и `main`. Для печати
    это неважно, а вот позже для проверки победы — очень удобно: не
    надо копировать поле туда-сюда.
- `if (row < 2)` — линию-разделитель рисуем после строк 0 и 1, но **не**
  после последней строки 2. Иначе под полем повисла бы лишняя черта.
- `printf("\n")` в начале и в конце — пустые строки сверху и снизу,
  чтобы поле не липло к остальному тексту.

Теперь `main` короткий: завести поле, заполнить, позвать `print_board`.
Запуск даёт аккуратную картинку:

```text
 1 | 2 | 3
---+---+---
 4 | 5 | 6
---+---+---
 7 | 8 | 9
```

## Шаг 3. Один ход игрока

Теперь научимся ставить фигуру. Игрок вводит число 1–9, а нам нужны два
индекса `[row][col]`. Как перевести одно в другое?

Клетки пронумерованы построчно: 1, 2, 3 — первая строка; 4, 5, 6 —
вторая; 7, 8, 9 — третья. Вычтем из номера 1, чтобы считать с нуля
(`cell - 1` даёт 0…8), и дальше:

- **номер строки** = `(cell - 1) / 3` — целочисленное деление на 3
  (помнишь из главы 2: `/` для целых отбрасывает дробь). Для клеток 1–3
  даст 0, для 4–6 даст 1, для 7–9 даст 2.
- **номер столбца** = `(cell - 1) % 3` — остаток от деления на 3. Даёт
  0, 1, 2 внутри строки.

Проверь руками. Клетка 5: `(5-1)/3 = 4/3 = 1` (строка 1), `(5-1)%3 =
4%3 = 1` (столбец 1) — центр `board[1][1]`. Верно. Клетка 7:
`(7-1)/3 = 2`, `(7-1)%3 = 0` — `board[2][0]`, левый нижний угол. Тоже
верно.

Наивный ход (пока без проверок):

```c
int cell;
scanf("%d", &cell);

int row = (cell - 1) / 3;
int col = (cell - 1) % 3;

board[row][col] = player;     // player — это 'X' или 'O'
```

Работает, но доверять вводу нельзя. Что если игрок наберёт 42? Тогда
`row = 41/3 = 13` — и мы запишем фигуру **за границы** массива, в чужую
память. Си границы не проверяет (см. главу 3), поэтому проверяем сами.

## Шаг 4. Проверяем ввод

Хороший ход обязан пройти три проверки:

1. Введено вообще число? (`scanf` мог не справиться — игрок набрал
   буквы).
2. Число в диапазоне 1–9?
3. Клетка свободна (там ещё цифра, а не `'X'`/`'O'`)?

```c
int cell;
int rc = scanf("%d", &cell);

if (rc == EOF) {                 /* ввод закончился (Ctrl+D) */
    printf("\nИгра прервана.\n");
    return 0;
}
if (rc != 1) {                   /* ввели не число */
    printf("Это не число. Введи цифру от 1 до 9.\n");
    int c;
    while ((c = getchar()) != '\n' && c != EOF) {
        /* выбрасываем мусорный ввод до конца строки */
    }
    continue;
}
if (cell < 1 || cell > 9) {
    printf("Нет такой клетки. Нужно число от 1 до 9.\n");
    continue;
}

int row = (cell - 1) / 3;
int col = (cell - 1) % 3;

if (board[row][col] == 'X' || board[row][col] == 'O') {
    printf("Клетка %d уже занята. Выбери другую.\n", cell);
    continue;
}
```

Разбор (часть уже знакома по игре «угадай число» из главы 12):

- `int rc = scanf("%d", &cell);` — `scanf` **возвращает**, сколько
  значений ему удалось прочитать. Мы просили одно число, значит, успех
  — это `rc == 1`. Раньше мы возвращаемое значение `scanf` игнорировали;
  здесь оно важно, потому что ввод может быть «грязным».
- `rc == EOF` — *end of file*, «конец ввода». Бывает, если ввод
  закончился (например, нажали Ctrl+D или партию подали из файла).
  Просто выходим.
- `rc != 1` — `scanf` не смог прочитать число (игрок набрал `abc`).
  Беда в том, что эти буквы **остались** во входном буфере, и следующий
  `scanf` снова на них споткнётся — получится бесконечный поток ошибок.
  Поэтому чистим буфер циклом `getchar()` до конца строки. `getchar`
  читает по одному символу; крутим, пока не съедим перевод строки `'\n'`
  или не упрёмся в конец ввода.
- `continue;` — пропустить остаток тела цикла и сразу пойти на новую
  попытку ввода. Игрок ошибся — даём ему повторить ход, не меняя поле и
  не передавая ход сопернику.
- `board[row][col] == 'X' || board[row][col] == 'O'` — клетка занята,
  если в ней стоит любая из фигур. Сравниваем символы через `==`
  (для одиночных `char` это можно — это не строки, см. главу 3, где
  строки нельзя сравнивать через `==`).

Только пройдя все проверки, ставим фигуру: `board[row][col] = player;`.

## Шаг 5. Проверка победы — выносим в функцию

После хода нужно понять, не выиграл ли текущий игрок. Проверять восемь
линий прямо в `main` — это каша. Вынесем в функцию `has_won`, которая
отвечает на вопрос «занял ли игрок `player` три клетки в ряд?».

```c
int has_won(char board[3][3], char player)
{
    for (int row = 0; row < 3; row++) {
        if (board[row][0] == player &&
            board[row][1] == player &&
            board[row][2] == player) {
            return 1;
        }
    }
    for (int col = 0; col < 3; col++) {
        if (board[0][col] == player &&
            board[1][col] == player &&
            board[2][col] == player) {
            return 1;
        }
    }
    if (board[0][0] == player &&
        board[1][1] == player &&
        board[2][2] == player) {
        return 1;
    }
    if (board[0][2] == player &&
        board[1][1] == player &&
        board[2][0] == player) {
        return 1;
    }
    return 0;
}
```

Разбор:

- `int has_won(...)` — функция возвращает `int`: 1, если игрок выиграл,
  0, если нет. Мы помним из главы 2: в Си истина — это любое ненулевое
  число (обычно 1), ложь — 0. Так что результат можно прямо подставлять
  в `if`.
- **Три строки.** Цикл по `row`: внутри строки фиксируем номер строки и
  проверяем все три столбца — `[row][0]`, `[row][1]`, `[row][2]`. Если
  все три равны `player`, строка собрана — `return 1`.
- **Три столбца.** Зеркально: цикл по `col`, фиксируем столбец и
  проверяем три строки — `[0][col]`, `[1][col]`, `[2][col]`.
- `&&` — логическое «И» (см. главу 2): победа в линии, только если
  **все три** клетки совпали с `player`.
- **Главная диагональ** — клетки `[0][0]`, `[1][1]`, `[2][2]` (из левого
  верхнего угла в правый нижний). **Побочная** — `[0][2]`, `[1][1]`,
  `[2][0]` (из правого верхнего в левый нижний). У обеих центр общий —
  `[1][1]`.
- `return 1;` внутри прерывает функцию сразу, как только нашли линию.
  Если ни одна не сложилась, доходим до `return 0;` в конце.

`return` где угодно завершает функцию и отдаёт значение. Поэтому первое
же совпадение даёт ответ, остальное не проверяется.

## Шаг 6. Проверка ничьей

Ничья — это когда ходов больше нет, а победителя нет. «Ходов нет»
значит, что все девять клеток заняты фигурами. Проверим это функцией:

```c
int board_is_full(char board[3][3])
{
    for (int row = 0; row < 3; row++) {
        for (int col = 0; col < 3; col++) {
            if (board[row][col] != 'X' && board[row][col] != 'O') {
                return 0;
            }
        }
    }
    return 1;
}
```

Логика «от противного»: ищем хотя бы одну **не**занятую клетку. Если в
клетке не `'X'` и не `'O'` (там ещё цифра-подсказка) — поле не
заполнено, сразу `return 0`. Если оба вложенных цикла отработали и ни
одной свободной клетки не нашлось — `return 1`, поле полное.

Порядок проверок в игре важен: **сначала** победа, **потом** ничья.
Последним, девятым, ходом игрок может одновременно и заполнить поле, и
выстроить линию — это победа, а не ничья. Поэтому в `main` сначала зовём
`has_won`, и только если победы нет — `board_is_full`.

## Полная программа

Собираем всё вместе. Это `code/15-tic-tac-toe.c`:

```c
#include <stdio.h>

/* Печать поля 3x3 с разделителями. */
void print_board(char board[3][3])
{
    printf("\n");
    for (int row = 0; row < 3; row++) {
        printf(" %c | %c | %c \n",
               board[row][0], board[row][1], board[row][2]);
        if (row < 2) {
            printf("---+---+---\n");
        }
    }
    printf("\n");
}

/* Проверка: занял ли игрок player три клетки в ряд?
   Возвращает 1 (победа) или 0. */
int has_won(char board[3][3], char player)
{
    /* три строки */
    for (int row = 0; row < 3; row++) {
        if (board[row][0] == player &&
            board[row][1] == player &&
            board[row][2] == player) {
            return 1;
        }
    }
    /* три столбца */
    for (int col = 0; col < 3; col++) {
        if (board[0][col] == player &&
            board[1][col] == player &&
            board[2][col] == player) {
            return 1;
        }
    }
    /* главная диагональ */
    if (board[0][0] == player &&
        board[1][1] == player &&
        board[2][2] == player) {
        return 1;
    }
    /* побочная диагональ */
    if (board[0][2] == player &&
        board[1][1] == player &&
        board[2][0] == player) {
        return 1;
    }
    return 0;
}

/* Все девять клеток заняты фигурами? */
int board_is_full(char board[3][3])
{
    for (int row = 0; row < 3; row++) {
        for (int col = 0; col < 3; col++) {
            if (board[row][col] != 'X' && board[row][col] != 'O') {
                return 0;
            }
        }
    }
    return 1;
}

int main(void)
{
    char board[3][3];

    /* Заполняем поле цифрами '1'..'9' — это подсказка номеров клеток. */
    char digit = '1';
    for (int row = 0; row < 3; row++) {
        for (int col = 0; col < 3; col++) {
            board[row][col] = digit;
            digit++;
        }
    }

    char player = 'X';   /* первым ходит X */
    int moves = 0;       /* сколько ходов сделано */

    printf("Крестики-нолики. Игроки X и O ходят по очереди.\n");
    printf("Выбирай клетку числом от 1 до 9.\n");

    while (1) {
        print_board(board);
        printf("Ход игрока %c. Клетка (1-9): ", player);

        int cell;
        int rc = scanf("%d", &cell);

        if (rc == EOF) {                 /* ввод закончился (Ctrl+D) */
            printf("\nИгра прервана.\n");
            return 0;
        }
        if (rc != 1) {                   /* ввели не число */
            printf("Это не число. Введи цифру от 1 до 9.\n");
            int c;
            while ((c = getchar()) != '\n' && c != EOF) {
                /* выбрасываем мусорный ввод до конца строки */
            }
            continue;
        }
        if (cell < 1 || cell > 9) {
            printf("Нет такой клетки. Нужно число от 1 до 9.\n");
            continue;
        }

        /* Переводим номер 1..9 в индексы строки и столбца. */
        int row = (cell - 1) / 3;
        int col = (cell - 1) % 3;

        if (board[row][col] == 'X' || board[row][col] == 'O') {
            printf("Клетка %d уже занята. Выбери другую.\n", cell);
            continue;
        }

        board[row][col] = player;        /* ставим фигуру */
        moves++;

        if (has_won(board, player)) {
            print_board(board);
            printf("Победил игрок %c! Ходов: %d.\n", player, moves);
            return 0;
        }
        if (board_is_full(board)) {
            print_board(board);
            printf("Ничья! Поле заполнено.\n");
            return 0;
        }

        /* Меняем игрока: X -> O, O -> X. */
        if (player == 'X') {
            player = 'O';
        } else {
            player = 'X';
        }
    }
}
```

## Как это работает

- Три функции стоят **выше** `main` — чтобы к моменту их вызова
  компилятор их уже знал (про это правило мы говорили в главе 2).
- `while (1)` — **бесконечный** цикл. `1` — это всегда истина, значит,
  условие никогда не станет ложным само. Это удобно для игрового цикла:
  один оборот = один ход. Выходим из него не по условию, а изнутри —
  через `return 0;` (победа, ничья или прерывание ввода). Так часто
  оформляют игры, где заранее неизвестно, сколько будет ходов.
- Один оборот цикла: показали поле → попросили ход → проверили ввод →
  поставили фигуру → проверили победу → проверили ничью → сменили
  игрока → и заново.
- Смена игрока в конце оборота: `'X'` становится `'O'` и наоборот. А
  если ход был отбракован (`continue`), мы до смены игрока не доходим —
  ход остаётся за тем же игроком. Это правильно: за чужую ошибку
  очередь не переходит.
- `moves` считает только **состоявшиеся** ходы (мы увеличиваем его
  после всех проверок). В конце печатаем, за сколько ходов выиграли.

## Проверяем

Скомпилируй и запусти. Компиляция должна пройти без единого
предупреждения:

```text
cc -std=c11 -Wall -Wextra -O2 15-tic-tac-toe.c -o ttt
./ttt
```

Сыграть можно вручную, набирая клетки и нажимая Enter. Но проверить, что
победа и ничья распознаются верно, удобнее «прокруткой» готовой партии
через канал ввода. Подадим серию ходов сразу, командой `printf`:

```text
printf "1\n4\n2\n5\n3\n" | ./ttt
```

Здесь `\n` — перевод строки (как нажатие Enter после каждого числа), а
`|` направляет этот текст программе на вход вместо клавиатуры. Партия:
X берёт 1, O берёт 4, X берёт 2, O берёт 5, X берёт 3 — и X собирает всю
верхнюю строку. Вывод (конец партии):

```text
Ход игрока X. Клетка (1-9): 
 X | X | X 
---+---+---
 O | O | 6 
---+---+---
 7 | 8 | 9 

Победил игрок X! Ходов: 5.
```

Победа по строке работает. Проверим **ничью** — заполним всё поле так,
чтобы линии ни у кого не сложилось:

```text
printf "1\n2\n3\n5\n4\n6\n8\n7\n9\n" | ./ttt
```

Конец партии:

```text
 X | O | X 
---+---+---
 X | O | O 
---+---+---
 O | X | X 

Ничья! Поле заполнено.
```

А вот победа по **диагонали** (`printf "5\n1\n3\n2\n7\n"` — X занимает
5, 3 и 7, это побочная диагональ):

```text
 O | O | X 
---+---+---
 4 | X | 6 
---+---+---
 X | 8 | 9 

Победил игрок X! Ходов: 5.
```

Читается так: X стоит в клетках 3, 5 и 7 — это побочная диагональ,
идущая из правого верхнего угла в левый нижний. O успел занять 1 и 2,
но линию не собрал. Клетки 4, 6, 8, 9 остались с цифрами-подсказками —
до них партия не дошла.

Все три исхода — строка, диагональ и ничья — определяются верно.

## Частые ошибки

**Путаница «номер клетки» и «индекс».** Игрок думает клетками 1–9, а
массив — индексами 0–8 по каждому измерению. Если забыть `- 1` в
`(cell - 1) / 3`, всё поле «съедет», а клетка 9 вообще улетит за
границы. Перевод номера в индексы делай в одном месте и проверяй руками
на паре примеров.

**Проверка занятости через цифру.** Можно подумать: «клетка свободна,
если в ней цифра». Но тогда условие пришлось бы писать длинно
(`>= '1' && <= '9'`). Надёжнее наоборот: клетка **занята**, если в ней
`'X'` или `'O'`. Свободна — во всех остальных случаях. Так не зависишь
от того, чем именно помечены пустые клетки.

**Грязный буфер ввода.** Если игрок вместо числа набрал буквы, `scanf`
их не прочитает и **оставит** во входном потоке. Без чистки буфера
(`getchar` до конца строки) следующий `scanf` снова на них наткнётся —
и игра уйдёт в бесконечную печать «Это не число». Всегда подчищай за
неудачным `scanf`.

**Сначала ничья, потом победа.** Если проверять `board_is_full` раньше
`has_won`, то выигрышный девятый ход засчитается как ничья. Победа
проверяется первой.

**Выход за границы при невалидной клетке.** Вычислять `row`/`col` и
лезть в `board[row][col]` нужно **только после** проверки `cell` на
диапазон 1–9. Иначе число 42 уведёт индекс за пределы массива, а Си это
не остановит (см. главу 3).

## Упражнения

1. **Счёт серий.** Сейчас после партии программа завершается. Оберни
   игру во внешний цикл: после результата спроси «Сыграем ещё? (y/n)» и,
   если да, начни новую партию. Веди счёт побед X, побед O и ничьих,
   печатай его перед каждой партией.

2. **Поле N×N.** Замени `board[3][3]` на `board[N][N]`, где `N` —
   константа (`#define N 3` вверху файла). Перепиши печать и заполнение
   через циклы до `N`. Победу пока можешь оставить на 3 в ряд только для
   `N == 3` — но печать и ввод должны работать при любом `N`.

3. **Ввод строкой и столбцом.** Вместо номера 1–9 разреши вводить два
   числа — номер строки и номер столбца (1–3 каждый). Переведи их в
   индексы (`row - 1`, `col - 1`) и проверь диапазон обоих.

4. **Простой бот.** Сделай так, чтобы за O играл компьютер. Самый
   наивный бот: пройди поле и поставь O в **первую попавшуюся**
   свободную клетку. Подключи `rand` (см. главу 12), чтобы бот выбирал
   свободную клетку случайно — так интереснее.

5. **Подсветка победной линии.** После победы не просто объяви
   победителя, а определи, какая именно линия собрана, и напечатай её
   (например, «верхняя строка» или «главная диагональ»). Подсказка:
   пусть `has_won` возвращает не просто 1, а номер линии.

6. **Защита от дурака в боте.** Усложни бота из задачи 4: перед своим
   ходом пусть он проверит, не может ли соперник выиграть следующим
   ходом, и закроет эту клетку.

## Что мы получили

Ты собрал полноценную игру с полем — и по дороге освоил **двумерный
массив**: два индекса `[строка][столбец]`, построчную раскладку в
памяти, обход вложенными циклами. Научился переводить номер клетки в
пару индексов через `/` и `%`, аккуратно проверять ввод, выносить логику
в функции (`print_board`, `has_won`, `board_is_full`) и проверять победу
по строкам, столбцам и диагоналям.

Двумерное поле плюс вложенные циклы — это каркас почти любой настольной
игры. В следующей главе мы возьмём поле побольше и поинтереснее:
напишем **сапёр**. Там тоже сетка клеток, но добавятся спрятанные мины,
подсчёт мин-соседей вокруг каждой клетки (привет, обход восьми
соседей) и рекурсивное «открытие» пустых областей.
