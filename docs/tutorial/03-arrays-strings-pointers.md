# Глава 3. Массивы, строки, указатели и память

Один `int` хранит одно число. Но алгоритмы работают с **наборами**:
отсортировать список оценок, найти слово в тексте, разложить колоду
карт. Для этого нужны три кита, на которых стоит весь Си: **массивы**
(много значений подряд), **строки** (текст) и **указатели** (адреса в
памяти). Разберём их по очереди, как всегда — строя и запуская.

## Часть 1. Массив — много коробок в ряд

**Массив** — это несколько переменных одного типа, лежащих в памяти
**подряд**, под общим именем. К каждой обращаемся по **номеру** —
*индексу*.

```c
#include <stdio.h>

int main(void)
{
    int marks[5] = {4, 5, 3, 5, 2};
    printf("Первая оценка: %d\n", marks[0]);
    printf("Третья оценка: %d\n", marks[2]);
    return 0;
}
```

Разбор:

- `int marks[5]` — объявляем массив из **5** целых чисел. Число в
  квадратных скобках — **размер**, сколько элементов. Он
  фиксированный: массив на 5 не станет на 6.
- `= {4, 5, 3, 5, 2}` — сразу заполняем пятью значениями в фигурных
  скобках.
- `marks[0]` — обращение к элементу по индексу. **Внимание:
  нумерация с нуля!** Первый элемент — `marks[0]`, второй — `marks[1]`,
  …, пятый и последний — `marks[4]`. Это сбивает с толку поначалу, но
  так во всех серьёзных языках.

### Перебор массива циклом

Массив и цикл `for` созданы друг для друга:

```c
int marks[5] = {4, 5, 3, 5, 2};
int sum = 0;
for (int i = 0; i < 5; i++) {
    sum = sum + marks[i];
}
printf("Сумма: %d\n", sum);
printf("Среднее: %.2f\n", (double)sum / 5);
```

- `i` пробегает от 0 до 4 (`i < 5`, не `<=`!). Если написать `i <= 5`,
  на последнем шаге обратимся к `marks[5]` — а его **нет**, индексы
  только 0..4. Это **выход за границы массива** — одна из самых
  опасных ошибок в Си. Язык **не проверяет** границы: он молча
  прочитает чужой кусок памяти или испортит данные. Следи за условием
  сам.
- `(double)sum / 5` — мы привели `sum` к дробному типу перед делением,
  иначе среднее посчиталось бы нацело. Запись `(тип)значение`
  называется **приведением типа** (cast).

### Заполнение массива вводом

```c
int n;
printf("Сколько чисел? ");
scanf("%d", &n);

int a[100];                    // место под 100 чисел
for (int i = 0; i < n; i++) {
    printf("a[%d] = ", i);
    scanf("%d", &a[i]);        // &a[i] — адрес i-го элемента
}
```

Здесь `&a[i]` — адрес конкретного элемента, куда `scanf` запишет
число. Мы объявили массив с запасом (100), а используем только первые
`n`. Так часто делают, пока не познакомимся с динамической памятью.

## Часть 2. Строки — это массивы символов

В Си **нет** отдельного типа «строка». Строка — это **массив `char`**,
в конце которого стоит специальный символ-метка `'\0'` (нулевой
символ, код 0). Он говорит: «здесь текст закончился».

```c
char name[] = "Анна";
```

Что произошло:

- `char name[]` — массив символов. Размер не указали — компилятор
  посчитает сам.
- `"Анна"` — компилятор разложит строку по буквам и **сам добавит**
  `'\0'` в конце. То есть в памяти лежит: `А`, `н`, `н`, `а`, `\0`.
  Хотя букв 4, размер массива — минимум 5 (плюс `\0`). (С русскими
  буквами в UTF-8 байт даже больше — об этом ниже.)

Печатают строку через `%s` (*string*):

```c
printf("Привет, %s!\n", name);
```

`printf` берёт символы от начала и печатает, **пока не встретит**
`'\0'`. Вот зачем нужен нулевой символ: без него `printf` не знал бы,
где остановиться, и печатал бы мусор дальше по памяти.

### Чтение строки от пользователя

Для слова без пробелов годится `%s` в `scanf`:

```c
char word[64];
printf("Введи слово: ");
scanf("%63s", word);
printf("Ты ввёл: %s\n", word);
```

Тонкости:

- В `scanf("%63s", word)` перед `word` **нет** `&`! Имя массива само
  по себе уже означает адрес его начала (об этом — в части про
  указатели). Это исключение из правила «всегда `&`».
- `%63s` с числом — мы ограничили ввод 63 символами, чтобы не
  переполнить массив из 64 (последний байт — под `'\0'`). Без
  ограничения слишком длинный ввод **затрёт соседнюю память** —
  классическая уязвимость.

Чтобы прочитать **целую строку с пробелами**, `scanf("%s")` не
годится (он читает до первого пробела). Берём `fgets`:

```c
char line[100];
printf("Введи фразу: ");
fgets(line, sizeof line, stdin);
```

- `fgets(куда, сколько_максимум, откуда)` — читает строку.
- `sizeof line` — размер массива `line` в байтах (100). Оператор
  `sizeof` возвращает размер; так `fgets` не вылезет за границу.
- `stdin` — *standard input*, стандартный ввод (клавиатура).
- Особенность: `fgets` оставляет в строке символ перевода строки
  `'\n'` (от нажатия Enter). Часто его убирают. Как — увидим в главе
  про строковые алгоритмы.

**Никогда не используй `gets`.** Это старая функция чтения строки без
ограничения длины; она настолько небезопасна, что её убрали из языка.
Только `fgets`.

### Полезные функции для строк (`<string.h>`)

Подключив `#include <string.h>`, получаем готовые инструменты:

- `strlen(s)` — длина строки (число символов до `'\0'`, сам `'\0'` не
  считается).
- `strcmp(a, b)` — сравнить две строки. Возвращает 0, если они
  **равны**. (Да, именно 0 при равенстве — это сбивает с толку.)
- `strcpy(dst, src)` — скопировать строку `src` в `dst`.

Сравнивать строки через `==` **нельзя** — это сравнит адреса, а не
содержимое. Только `strcmp`. Запомни сразу, эта ошибка очень частая:

```c
if (strcmp(word, "выход") == 0) {   // правильно
    printf("Пока!\n");
}
```

## Часть 3. Указатели — переменные, хранящие адрес

Мы уже встречали `&` в `scanf` — «адрес переменной». Теперь разберём
это до конца, потому что без указателей не написать функцию, меняющую
свои аргументы, и не понять динамическую память.

У каждой переменной есть **адрес** — номер ячейки в памяти, где она
лежит. **Указатель** — это переменная, которая хранит такой адрес.

```c
#include <stdio.h>

int main(void)
{
    int x = 42;
    int *p = &x;     // p хранит адрес x

    printf("значение x:        %d\n", x);
    printf("адрес x:           %p\n", (void *)&x);
    printf("p хранит адрес:    %p\n", (void *)p);
    printf("значение по p:     %d\n", *p);

    *p = 100;        // меняем x через указатель
    printf("теперь x = %d\n", x);
    return 0;
}
```

Разбор — это ключевой момент всей главы:

- `int *p` — объявляем **указатель на int**. Звёздочка `*` в
  объявлении говорит: «`p` — не число, а адрес, по которому лежит
  число». Тип — «указатель на `int`».
- `= &x` — кладём в `p` **адрес** переменной `x`. Оператор `&` —
  «взять адрес».
- `*p` (в коде, не в объявлении) — оператор **разыменования**:
  «значение, лежащее **по** адресу `p`». Это как «открыть коробку, на
  которую указывает стрелка». `*p` — это и есть `x`, просто доступ к
  нему через адрес.
- `*p = 100;` — записать 100 туда, куда указывает `p`. Поскольку `p`
  указывает на `x`, изменится именно `x`. После этой строки `x` равен
  100.
- `%p` — спецификатор для печати адреса; `(void *)` — приведение,
  которого требует `printf` для адресов. Конкретные числа адресов у
  тебя будут свои.

Запутаться легко, поэтому короткая шпаргалка:

- `&x` — «**адрес** переменной x» (был у scanf).
- `int *p` — «p это **указатель**».
- `*p` — «**значение по** указателю p».

### Зачем это нужно: функция, меняющая аргумент

В Си аргументы передаются **по значению** — функция получает копию.
Поэтому такая функция не сработает:

```c
void bad_swap(int a, int b) {   // меняет местами КОПИИ — бесполезно
    int t = a; a = b; b = t;
}
```

Снаружи ничего не изменится. Чтобы функция поменяла **сами**
переменные, передаём их **адреса**:

```c
void swap(int *a, int *b)   // принимаем адреса
{
    int t = *a;             // запомнили значение по a
    *a = *b;                // в a положили значение по b
    *b = t;                 // в b положили запомненное
}

int main(void)
{
    int x = 1, y = 2;
    swap(&x, &y);           // передаём адреса x и y
    printf("x=%d y=%d\n", x, y);   // x=2 y=1
    return 0;
}
```

Это и есть причина, по которой `scanf` требует `&`: ему нужен адрес,
чтобы записать прочитанное в **твою** переменную, а не в копию.

### Массив и указатель — близкие родственники

Имя массива в большинстве выражений превращается в **адрес его
первого элемента**. Поэтому `scanf("%s", word)` работает без `&`:
`word` — это уже адрес. И поэтому, когда передаёшь массив в функцию,
функция получает адрес начала и может менять его содержимое. Этим мы
будем пользоваться постоянно в сортировках.

## Часть 4. Динамическая память — когда размер заранее неизвестен

`int a[100]` требует знать размер при написании кода. А если число
элементов выяснится только во время работы? Тогда память просят у
системы **во время выполнения** — это **динамическая память**.

Нужен `#include <stdlib.h>` и две функции: `malloc` (попросить память)
и `free` (вернуть).

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int n;
    printf("Сколько чисел? ");
    scanf("%d", &n);

    int *a = malloc(n * sizeof(int));   // память под n чисел
    if (a == NULL) {                    // вдруг память не дали
        printf("Не хватило памяти\n");
        return 1;
    }

    for (int i = 0; i < n; i++) {
        a[i] = i * i;                   // к malloc-памяти — как к массиву
    }
    for (int i = 0; i < n; i++) {
        printf("%d ", a[i]);
    }
    printf("\n");

    free(a);                            // вернули память системе
    return 0;
}
```

Разбор:

- `malloc(n * sizeof(int))` — просим столько байт, сколько занимают
  `n` целых. `sizeof(int)` — размер одного `int` в байтах (обычно 4).
  `malloc` (*memory allocate*) возвращает **адрес** выделенного куска,
  поэтому результат кладём в указатель `int *a`.
- `if (a == NULL)` — `malloc` может вернуть `NULL` («нулевой адрес,
  никуда не указывает»), если памяти не хватило. Проверять это —
  хорошая привычка. `NULL` — специальное значение «указатель в
  никуда».
- `a[i]` — к динамической памяти обращаемся **точно как к массиву**.
  Указатель и массив здесь неотличимы в использовании.
- `free(a);` — **обязательно** возвращаем память, когда она больше не
  нужна. Если этого не делать, программа будет занимать всё больше
  памяти — это **утечка памяти** (memory leak). Правило: на каждый
  `malloc` однажды должен прийтись `free`.

## Замечание про русские буквы

Современные системы хранят текст в кодировке **UTF-8**, где русская
буква занимает **2 байта**, а не 1. Поэтому `strlen("Привет")` вернёт
12, а не 6, и посимвольная обработка кириллицы — отдельная морока. В
этой книге, где важно считать **символы**, мы будем работать с
латиницей и цифрами (по 1 байту). Для вывода сообщений русский текст
полностью годится — `printf` печатает байты как есть, и всё выглядит
правильно.

## Частые ошибки

**Выход за границы массива.** `for (i = 0; i <= n; ...)` вместо
`i < n`. Си не проверяет границы — получишь порчу памяти или падение.

**Сравнение строк через `==`.** Сравнивает адреса, не текст. Нужен
`strcmp`.

**Забыл `'\0'`.** Если собираешь строку вручную по символам, не забудь
поставить `'\0'` в конце, иначе `printf("%s")` улетит в мусор.

**`malloc` без проверки на `NULL`** и **без `free`.** Первое —
возможное падение, второе — утечка.

**`*` путается в объявлении и в использовании.** В `int *p` звёздочка
объявляет указатель; в `*p = 5` — разыменовывает. Это разные роли
одного знака.

## Упражнения

1. Заполни массив из 10 чисел вводом и напечатай его в обратном
   порядке.
2. Найди в массиве максимальный элемент (заведи переменную `max`,
   пройди циклом, обновляй её).
3. Напиши функцию `void fill(int *a, int n, int value)`, которая
   заполняет первые `n` элементов значением `value`.
4. Прочитай слово через `scanf("%63s", ...)` и напечатай его длину
   через `strlen`.
5. Через `malloc` выдели массив на введённое число элементов,
   заполни их кубами индексов (`i*i*i`), напечатай и не забудь `free`.
