# Глава 17. Игра «Змейка»

Вот мы и добрались до финала. «Змейка» — та самая игра из старых
телефонов: по полю ползёт змейка, ест еду, растёт и не должна
врезаться ни в стену, ни в саму себя. Игра простая на вид, но в ней
сходится всё, что мы прошли: двумерное поле, массивы координат,
структура состояния, случайная еда, цикл и проверки столкновений.

И тут появляется по-настоящему новое. Раньше наши программы ждали,
пока ты нажмёшь клавишу и Enter. Змейка так не умеет: она ползёт
**сама**, а клавишу должна ловить **мгновенно**, без Enter и без
эха на экране. За это отвечает «сырой» режим терминала через
`termios` — главная новая тема главы. Разберём её спокойно и по
частям.

## Что мы сделаем

К концу главы у тебя будет настоящая игра в терминале:

- поле с рамкой из символов `#`;
- змейка (`O` — голова, `o` — тело), которая ползёт сама;
- управление клавишами W A S D **без нажатия Enter**;
- еда `*`, которая появляется в случайном месте; съел — змейка растёт
  и счёт увеличивается;
- проигрыш при столкновении со стеной или с собственным телом;
- выход по клавише `q`.

Строить будем как всегда: от простого к сложному. Сначала просто
нарисуем поле и неподвижную змейку. Потом заставим её двигаться. Потом
научимся ловить клавиши. Потом добавим еду и рост. И в конце —
столкновения и проигрыш.

## Разбираем задачу руками

Прежде чем писать код, поймём две вещи: как хранить змейку и почему
обычного ввода тут не хватит.

### Как хранить змейку

Змейка — это цепочка клеток на поле. Каждая клетка — пара чисел:
номер столбца `x` и номер строки `y`. Заведём два массива:

```text
snake_x:  9  8  7
snake_y:  5  5  5
```

Это змейка из трёх сегментов на одной строке. Элемент с индексом `0`
— **голова** (`x=9, y=5`), дальше идёт тело. Длину храним отдельно в
переменной `snake_len`.

Как змейка делает шаг? Представь гусеницу: каждый сегмент
переползает на место предыдущего, а голова делает шаг в новую
клетку. Сдвинули тело — поставили новую голову. Всё.

```text
было:   голова(9,5)  тело(8,5)  тело(7,5)
сдвиг:  ?(9,5)        (9,5)      (8,5)      <- каждый занял место соседа
голова: (10,5)        (9,5)      (8,5)      <- голова шагнула вправо
```

Направление движения тоже храним парой чисел `dir_x, dir_y`:
вправо — это `(1, 0)`, влево — `(-1, 0)`, вверх — `(0, -1)`, вниз —
`(0, 1)`. Обрати внимание: вверх — это **минус** по `y`, потому что
строки нумеруются сверху вниз (нулевая строка — самая верхняя).

### Почему обычный ввод не подходит

По умолчанию терминал работает в **каноническом режиме** (canonical
mode, его ещё зовут «строчным»). Это значит две вещи:

1. Терминал **ждёт Enter**. Что бы ты ни печатал, программа ничего не
   получит, пока ты не нажмёшь Enter. Вся строка копится в буфере.
2. Терминал **печатает эхо** — показывает на экране каждый набранный
   символ.

Для обычной программы это удобно: можно стереть опечатку до Enter. Но
для игры — катастрофа. Змейка должна реагировать на `d` сразу, а не
ждать Enter. И буквы `wasd` не должны замусоривать наше поле.

Значит, нам нужно временно выключить два этих поведения: ожидание
Enter и эхо. А ещё сделать чтение **неблокирующим** — чтобы программа
не зависала, ожидая клавишу, когда её не нажали. Змейка ведь ползёт и
без ввода.

Всё это делается через `termios` — набор настроек терминала в POSIX
(стандарт для macOS и Linux). На Windows механизм другой (там для той
же задачи берут `_getch` из `<conio.h>`), но мы пишем под
macOS/Linux.

## Шаг 1. Поле и неподвижная змейка

Начнём с самого простого: нарисуем рамку, змейку и еду — пока без
всякого движения. Цель шага — увидеть картинку.

```c
#include <stdio.h>

#define WIDTH   20
#define HEIGHT  10

int main(void)
{
    int snake_x[3] = {9, 8, 7};
    int snake_y[3] = {5, 5, 5};
    int snake_len = 3;

    /* верхняя рамка */
    for (int x = 0; x < WIDTH + 2; x++) {
        putchar('#');
    }
    putchar('\n');

    for (int y = 0; y < HEIGHT; y++) {
        putchar('#');                       /* левая стенка */
        for (int x = 0; x < WIDTH; x++) {
            char ch = ' ';
            for (int i = 0; i < snake_len; i++) {
                if (snake_x[i] == x && snake_y[i] == y) {
                    ch = (i == 0) ? 'O' : 'o';
                    break;
                }
            }
            putchar(ch);
        }
        putchar('#');                       /* правая стенка */
        putchar('\n');
    }

    /* нижняя рамка */
    for (int x = 0; x < WIDTH + 2; x++) {
        putchar('#');
    }
    putchar('\n');
    return 0;
}
```

Разбор нового:

- `#define WIDTH 20` — это **макрос-константа**. `#define ИМЯ
  значение` говорит компилятору: «перед сборкой замени везде в тексте
  слово `WIDTH` на `20`». Удобно: размер поля задан в одном месте,
  захочешь поле побольше — поменяешь одну строку. Точки с запятой в
  конце `#define` **не ставят**.
- `WIDTH` и `HEIGHT` — ширина и высота **внутренней** части поля, без
  рамки. Рамка добавляет по одному символу слева и справа, поэтому в
  цикле рамки идёт `WIDTH + 2`.
- `putchar('#')` — функция из `stdio.h`, печатает **один символ**.
  Это как `printf("%c", '#')`, только короче и быстрее. Аргумент —
  символ в одинарных кавычках.
- Внешний цикл по `y` идёт по строкам поля (0..HEIGHT−1), внутренний
  по `x` — по столбцам (0..WIDTH−1). Для каждой клетки `(x, y)`
  решаем, что в ней напечатать.
- `char ch = ' ';` — по умолчанию клетка пустая (пробел).
- Внутренний цикл `for (int i = 0; ...)` проверяет: не стоит ли в этой
  клетке сегмент змейки? Если координаты сегмента `i` совпали с `(x,
  y)`, рисуем символ.
- `ch = (i == 0) ? 'O' : 'o';` — это **тернарный оператор**
  (условное выражение). Читается так: «если `i == 0`, то значение
  `'O'`, иначе `'o'`». Короткая запись `if/else` прямо внутри
  выражения. Голова (индекс 0) — заглавная `O`, тело — строчная `o`.
- `break;` — как только нашли сегмент в клетке, выходим из
  внутреннего цикла: дальше проверять нет смысла.

Скомпилируй и запусти:

```text
######################
#                    #
#                    #
#                    #
#                    #
#                    #
#       ooO          #
#                    #
#                    #
#                    #
#                    #
######################
```

Поле есть, змейка на месте (голова `O` справа, тело `oo` слева). Но
она не двигается. Чиним.

## Шаг 2. Заставляем змейку ползти

Чтобы змейка двигалась, нужен **игровой цикл**: бесконечно повторяем
«сдвинули змейку → перерисовали поле → подождали чуть-чуть». А чтобы
картинка не уезжала вниз простынёй, перед каждой отрисовкой будем
**очищать экран**.

Очистка делается специальной командой для терминала —
**управляющей последовательностью** (escape sequence):

```c
printf("\033[H\033[2J");
```

Разберём по кускам:

- `\033` — это символ Escape (его код 27). Запись `\033` — код в
  восьмеричной системе. С него начинаются почти все команды
  управления терминалом. Терминал, увидев Escape и `[`, понимает:
  дальше не текст для печати, а команда.
- `\033[H` — команда «переместить курсор в левый верхний угол»
  (Home). Следующая печать пойдёт с самого верха.
- `\033[2J` — команда «стереть весь экран» (J — erase, 2 — целиком).

Вместе `\033[H\033[2J` — «очисти экран и поставь курсор в угол». Это
работает в любом нормальном терминале macOS/Linux.

Теперь сдвиг змейки. Как договорились, тело переползает по цепочке, а
голова шагает в направлении `dir`:

```c
/* сдвигаем тело: каждый сегмент встаёт на место предыдущего */
for (int i = snake_len - 1; i > 0; i--) {
    snake_x[i] = snake_x[i - 1];
    snake_y[i] = snake_y[i - 1];
}
/* голова делает шаг */
snake_x[0] += dir_x;
snake_y[0] += dir_y;
```

Важно идти **с хвоста к голове** (`i` от конца к 1). Если бы мы шли с
головы, то затёрли бы координаты, которые ещё нужны соседнему
сегменту.

Чтобы между кадрами была видимая пауза, нужна функция `usleep`
(*microsecond sleep* — «спать микросекунды»). Она из POSIX
(`<unistd.h>`):

```c
usleep(150000);   /* 150 000 микросекунд = 0,15 секунды */
```

В одной секунде миллион микросекунд, так что `150000` — это примерно
0,15 секунды между кадрами. Чем меньше число, тем быстрее змейка.

Маленькая, но важная деталь сборки. Мы пишем со стандартом `-std=c11`,
а `usleep` — функция POSIX, не из чистого C11. Чтобы компилятор её
«увидел», в самом начале файла добавим строку:

```c
#define _DEFAULT_SOURCE
```

Это «фича-макрос»: он включает доступ к POSIX-функциям (`usleep`,
`read`, `termios`) при строгом стандарте C11. Поставить его нужно
**до** всех `#include`.

Соберём шаг 2 целиком — змейка ползёт вправо сама:

```c
#define _DEFAULT_SOURCE
#include <stdio.h>
#include <unistd.h>

#define WIDTH   20
#define HEIGHT  10

int main(void)
{
    int snake_x[3] = {9, 8, 7};
    int snake_y[3] = {5, 5, 5};
    int snake_len = 3;
    int dir_x = 1, dir_y = 0;   /* ползём вправо */

    for (int step = 0; step < 8; step++) {   /* пока 8 шагов для пробы */
        printf("\033[H\033[2J");

        /* рисуем поле */
        for (int x = 0; x < WIDTH + 2; x++) putchar('#');
        putchar('\n');
        for (int y = 0; y < HEIGHT; y++) {
            putchar('#');
            for (int x = 0; x < WIDTH; x++) {
                char ch = ' ';
                for (int i = 0; i < snake_len; i++) {
                    if (snake_x[i] == x && snake_y[i] == y) {
                        ch = (i == 0) ? 'O' : 'o';
                        break;
                    }
                }
                putchar(ch);
            }
            putchar('#');
            putchar('\n');
        }
        for (int x = 0; x < WIDTH + 2; x++) putchar('#');
        putchar('\n');

        /* двигаем змейку */
        for (int i = snake_len - 1; i > 0; i--) {
            snake_x[i] = snake_x[i - 1];
            snake_y[i] = snake_y[i - 1];
        }
        snake_x[0] += dir_x;
        snake_y[0] += dir_y;

        usleep(150000);
    }
    return 0;
}
```

Запусти — увидишь, как змейка проползает вправо восемь шагов и
программа завершается. Уже живая картинка! Но управлять ей мы пока не
можем, а на стену она просто уедет. Добавим управление.

## Шаг 3. Ловим клавиши без Enter — сырой режим

Это сердце главы. Нам нужно:

1. выключить ожидание Enter и эхо (сырой режим);
2. читать клавишу **не блокируясь** — нет нажатия, идём дальше;
3. в конце игры **вернуть** терминал в обычное состояние.

Сначала подключаем заголовки:

```c
#include <termios.h>   /* настройки терминала */
#include <unistd.h>    /* read, STDIN_FILENO, usleep */
```

`<termios.h>` даёт структуру `struct termios` (набор флагов
терминала) и функции `tcgetattr`/`tcsetattr` (прочитать и записать
эти настройки). `STDIN_FILENO` из `<unistd.h>` — это номер
стандартного ввода (клавиатуры), равен 0.

### Включаем сырой режим

```c
static struct termios orig_termios;   /* сюда сохраним исходные настройки */

static void disable_raw_mode(void)
{
    tcsetattr(STDIN_FILENO, TCSANOW, &orig_termios);
}

static void enable_raw_mode(void)
{
    tcgetattr(STDIN_FILENO, &orig_termios);   /* запомнили как было */
    struct termios raw = orig_termios;        /* копия для правки */

    raw.c_lflag &= ~(ICANON | ECHO);          /* снять канонику и эхо */
    raw.c_cc[VMIN]  = 0;                       /* read не ждёт символов */
    raw.c_cc[VTIME] = 0;                       /* и не ждёт по таймеру */

    tcsetattr(STDIN_FILENO, TCSANOW, &raw);    /* применить сейчас же */
}
```

Разбираем по строчкам:

- `static struct termios orig_termios;` — глобальная переменная под
  исходные настройки. Слово `static` тут значит «видна только в этом
  файле». `struct termios` — структура с настройками терминала (про
  структуры мы говорили в главе 11).
- `tcgetattr(STDIN_FILENO, &orig_termios)` — **прочитать** текущие
  настройки терминала и сложить в `orig_termios`. `&` — адрес: функция
  запишет настройки в нашу переменную (как `scanf` пишет по адресу).
- `struct termios raw = orig_termios;` — делаем **копию**. Исходник
  `orig_termios` бережём нетронутым, чтобы в конце восстановить.
- `raw.c_lflag &= ~(ICANON | ECHO);` — самая важная строка. `c_lflag`
  — поле «локальных флагов» терминала; в нём набор включённых режимов.
  - `ICANON` — флаг канонического режима (ожидание Enter).
  - `ECHO` — флаг эха (печать набранного на экран).
  - `ICANON | ECHO` — операцией `|` (побитовое ИЛИ) объединяем оба
    флага в один набор битов.
  - `~(...)` — побитовое НЕ: переворачивает биты, получая «всё, кроме
    этих двух флагов».
  - `&=` — присвоить результат побитового И. Вместе строка означает:
    «оставить все флаги как есть, но **снять** `ICANON` и `ECHO`». Эта
    связка `flag &= ~(БИТЫ)` — стандартный способ выключить биты.
- `raw.c_cc[VMIN] = 0; raw.c_cc[VTIME] = 0;` — массив `c_cc` хранит
  «спецсимволы» и параметры чтения. `VMIN = 0` и `VTIME = 0` вместе
  означают: «чтение возвращает управление **сразу**, даже если ничего
  не нажато». Это и есть неблокирующее чтение — без `fcntl`, штатными
  средствами termios.
- `tcsetattr(STDIN_FILENO, TCSANOW, &raw)` — **записать** новые
  настройки. `TCSANOW` — «применить немедленно».
- `disable_raw_mode` делает обратное: возвращает сохранённый
  `orig_termios`. Её **обязательно** вызвать в конце, иначе после игры
  терминал останется без эха и будет вести себя странно.

### Читаем клавишу

```c
static int read_key(void)
{
    char c;
    ssize_t n = read(STDIN_FILENO, &c, 1);
    if (n == 1) {
        return (unsigned char)c;
    }
    return -1;
}
```

- `read(STDIN_FILENO, &c, 1)` — POSIX-функция чтения: «прочитать из
  стандартного ввода в переменную `c` максимум 1 байт». Возвращает,
  сколько байт реально прочла.
- `ssize_t` — целочисленный тип для результата `read` (может быть и
  отрицательным при ошибке). Считай его «специальным `int` для
  размеров».
- Если `n == 1` — клавишу нажали, возвращаем её код. Приведение
  `(unsigned char)` нужно, чтобы коды не ушли в отрицательные.
- Если нажатия не было, `read` вернёт 0 (мы же сделали неблокирующее
  чтение), и функция вернёт `-1` — «клавиши нет».

Теперь в `main` обернём всё: включим режим в начале, выключим в
конце, а в цикле будем спрашивать `read_key`. Реверс (резкий разворот
на 180°) запрещаем — иначе змейка мгновенно врежется в себя:

```c
static int dir_x, dir_y;

static void set_dir(int nx, int ny)
{
    if (nx == -dir_x && ny == -dir_y) {
        return;   /* противоположное текущему — игнорируем */
    }
    dir_x = nx;
    dir_y = ny;
}
```

`set_dir` меняет направление, но если новое — точная
противоположность текущему (`nx == -dir_x` и `ny == -dir_y`), просто
выходит, ничего не меняя.

В игровом цикле читаем **все** накопившиеся нажатия за кадр (вдруг ты
нажал несколько раз) и применяем их:

```c
int key;
while ((key = read_key()) != -1) {
    if (key == 'w' || key == 'W') set_dir(0, -1);
    else if (key == 's' || key == 'S') set_dir(0, 1);
    else if (key == 'a' || key == 'A') set_dir(-1, 0);
    else if (key == 'd' || key == 'D') set_dir(1, 0);
    else if (key == 'q' || key == 'Q') game_over = 1;
}
```

- `while ((key = read_key()) != -1)` — присваиваем результат
  `read_key()` переменной `key` **и тут же** сравниваем с `-1`. Пока
  клавиши есть, крутимся. Опустошили буфер — `read_key` вернёт `-1`,
  цикл закончится. Скобки вокруг `key = read_key()` обязательны.
- Дальше обычный разбор: WASD меняют направление (учитываем и
  заглавные на случай Caps Lock), `q` — выход.

Теперь змейкой можно рулить. Осталась еда, рост и проигрыш.

## Шаг 4. Еда, рост и счёт

Еда `*` лежит в случайной клетке. Съел — змейка прибавляет сегмент, а
счёт растёт. Заводим переменные `food_x, food_y, score`.

Случайные числа — из главы про `rand` (`<stdlib.h>`). Кладём еду в
свободную клетку:

```c
static void place_food(void)
{
    int ok = 0;
    while (!ok) {
        food_x = rand() % WIDTH;
        food_y = rand() % HEIGHT;
        ok = 1;
        for (int i = 0; i < snake_len; i++) {
            if (snake_x[i] == food_x && snake_y[i] == food_y) {
                ok = 0;   /* попали в тело — выбираем заново */
                break;
            }
        }
    }
}
```

- `rand() % WIDTH` — остаток от деления случайного числа на ширину
  даёт число в диапазоне 0..WIDTH−1, то есть допустимый столбец.
  Аналогично для строки.
- Цикл `while (!ok)` повторяет выбор, пока еда не окажется в пустой
  клетке: если случайно попали в тело змейки, ставим `ok = 0` и
  бросаем кубик заново.

Теперь рост. Хитрость в том, что при сдвиге тела последний сегмент
(хвост) «теряется» — его координаты затираются. Если змейка съела
еду, мы вернём этот хвост обратно, и она станет на сегмент длиннее.
Поэтому **перед** сдвигом запоминаем хвост:

```c
int tail_x = snake_x[snake_len - 1];
int tail_y = snake_y[snake_len - 1];

/* ...сдвиг тела и шаг головы как раньше... */

if (snake_x[0] == food_x && snake_y[0] == food_y) {
    if (snake_len < MAX_LEN) {
        snake_x[snake_len] = tail_x;   /* отрастили хвост обратно */
        snake_y[snake_len] = tail_y;
        snake_len++;
    }
    score += 10;
    place_food();
}
```

- `snake_len - 1` — индекс последнего сегмента (помни: нумерация с 0,
  поэтому последний — не `snake_len`, а на единицу меньше).
- Если голова попала на еду, добавляем новый сегмент в позицию
  бывшего хвоста: `snake_x[snake_len] = tail_x`, и увеличиваем длину.
- `if (snake_len < MAX_LEN)` — защита от выхода за границы массива:
  не даём длине превысить размер. `MAX_LEN` — максимум сегментов
  (все клетки поля).
- `score += 10` — за каждую еду 10 очков. После — кладём новую еду.

В отрисовку добавляем еду перед проверкой змейки:

```c
if (x == food_x && y == food_y) {
    ch = '*';
} else {
    /* ...поиск сегмента змейки, как раньше... */
}
```

## Шаг 5. Столкновения и конец игры

Последний штрих — проигрыш. Игра кончается, если голова вышла за
стену или наехала на собственное тело. Проверяем **после** шага
головы:

```c
/* столкновение со стеной */
if (snake_x[0] < 0 || snake_x[0] >= WIDTH ||
    snake_y[0] < 0 || snake_y[0] >= HEIGHT) {
    game_over = 1;
    return;
}

/* столкновение с собственным телом (со 2-го сегмента) */
for (int i = 1; i < snake_len; i++) {
    if (snake_x[i] == snake_x[0] && snake_y[i] == snake_y[0]) {
        game_over = 1;
        return;
    }
}
```

- Первое условие: голова ушла левее 0, правее поля, выше 0 или ниже
  поля — это удар о стену.
- Второй цикл начинается с `i = 1` (нулевой сегмент — сама голова,
  сравнивать её с собой бессмысленно). Если координаты головы совпали
  с любым сегментом тела — змейка укусила себя.
- `game_over = 1` поднимает флаг, `return` обрывает шаг: дальше еду
  проверять незачем.

Главный цикл крутится, пока `!game_over`. Как только флаг поднят (или
нажали `q`), выходим, **возвращаем терминал** и печатаем счёт. Собираем
всё вместе.

## Полная программа

Сохрани это как `code/17-snake.c`.

```c
/* Глава 17. Игра «Змейка» в терминале.
 *
 * Управление: W A S D — вверх/влево/вниз/вправо, q — выход.
 * Компиляция (macOS/Linux):
 *   cc -std=c11 -Wall -Wextra -O2 17-snake.c -o snake
 *
 * Программа интерактивная: запускать в обычном терминале, не в пайпе.
 */

#define _DEFAULT_SOURCE   /* открыть доступ к usleep, read, termios в C11 */

#include <stdio.h>
#include <stdlib.h>
#include <time.h>
#include <termios.h>
#include <unistd.h>

/* ---- Размеры игрового поля (без учёта рамки) ---- */
#define WIDTH   20
#define HEIGHT  10
#define MAX_LEN (WIDTH * HEIGHT)   /* змейка не длиннее всех клеток поля */

/* ---- Состояние игры ---- */
static int snake_x[MAX_LEN];   /* координаты сегментов: [0] — голова */
static int snake_y[MAX_LEN];
static int snake_len;          /* сколько сегментов сейчас */
static int dir_x, dir_y;       /* направление движения головы */
static int food_x, food_y;     /* где лежит еда */
static int score;              /* счёт */
static int game_over;          /* 0 — играем, 1 — конец */

/* ---- Сырой режим терминала ---- */
static struct termios orig_termios;   /* сюда сохраним исходные настройки */

/* Вернуть терминал в нормальный режим. */
static void disable_raw_mode(void)
{
    tcsetattr(STDIN_FILENO, TCSANOW, &orig_termios);
}

/* Включить «сырой» неблокирующий ввод: без ожидания Enter и без эха. */
static void enable_raw_mode(void)
{
    tcgetattr(STDIN_FILENO, &orig_termios);   /* запомнили как было */
    struct termios raw = orig_termios;        /* копия для правки */

    raw.c_lflag &= ~(ICANON | ECHO);          /* снять каноническ. режим и эхо */
    raw.c_cc[VMIN]  = 0;                       /* read не ждёт символов */
    raw.c_cc[VTIME] = 0;                       /* и не ждёт по таймеру */

    tcsetattr(STDIN_FILENO, TCSANOW, &raw);    /* применить сейчас же */
}

/* Прочитать одну клавишу. Если её нет — вернуть -1 (не ждём ввода). */
static int read_key(void)
{
    char c;
    ssize_t n = read(STDIN_FILENO, &c, 1);
    if (n == 1) {
        return (unsigned char)c;
    }
    return -1;
}

/* Положить еду в случайную свободную клетку. */
static void place_food(void)
{
    int ok = 0;
    while (!ok) {
        food_x = rand() % WIDTH;
        food_y = rand() % HEIGHT;
        ok = 1;
        for (int i = 0; i < snake_len; i++) {
            if (snake_x[i] == food_x && snake_y[i] == food_y) {
                ok = 0;   /* попали в тело — выбираем заново */
                break;
            }
        }
    }
}

/* Нарисовать поле, змейку, еду и счёт. */
static void draw(void)
{
    printf("\033[H\033[2J");   /* курсор в угол + очистка экрана */

    /* верхняя рамка */
    for (int x = 0; x < WIDTH + 2; x++) {
        putchar('#');
    }
    putchar('\n');

    for (int y = 0; y < HEIGHT; y++) {
        putchar('#');                       /* левая стенка */
        for (int x = 0; x < WIDTH; x++) {
            char ch = ' ';
            if (x == food_x && y == food_y) {
                ch = '*';                   /* еда */
            } else {
                for (int i = 0; i < snake_len; i++) {
                    if (snake_x[i] == x && snake_y[i] == y) {
                        ch = (i == 0) ? 'O' : 'o';   /* голова / тело */
                        break;
                    }
                }
            }
            putchar(ch);
        }
        putchar('#');                       /* правая стенка */
        putchar('\n');
    }

    /* нижняя рамка */
    for (int x = 0; x < WIDTH + 2; x++) {
        putchar('#');
    }
    putchar('\n');

    printf("Счёт: %d   (WASD — движение, q — выход)\n", score);
}

/* Сменить направление, не разрешая разворот на 180 градусов. */
static void set_dir(int nx, int ny)
{
    if (nx == -dir_x && ny == -dir_y) {
        return;   /* противоположное текущему — игнорируем */
    }
    dir_x = nx;
    dir_y = ny;
}

/* Один шаг змейки: сдвиг тела, новая голова, столкновения, еда. */
static void update(void)
{
    /* запомним хвост — он пригодится, если змейка вырастет */
    int tail_x = snake_x[snake_len - 1];
    int tail_y = snake_y[snake_len - 1];

    /* сдвигаем тело: каждый сегмент встаёт на место предыдущего */
    for (int i = snake_len - 1; i > 0; i--) {
        snake_x[i] = snake_x[i - 1];
        snake_y[i] = snake_y[i - 1];
    }

    /* голова делает шаг в текущем направлении */
    snake_x[0] += dir_x;
    snake_y[0] += dir_y;

    /* столкновение со стеной */
    if (snake_x[0] < 0 || snake_x[0] >= WIDTH ||
        snake_y[0] < 0 || snake_y[0] >= HEIGHT) {
        game_over = 1;
        return;
    }

    /* столкновение с собственным телом (со 2-го сегмента) */
    for (int i = 1; i < snake_len; i++) {
        if (snake_x[i] == snake_x[0] && snake_y[i] == snake_y[0]) {
            game_over = 1;
            return;
        }
    }

    /* съели еду? */
    if (snake_x[0] == food_x && snake_y[0] == food_y) {
        if (snake_len < MAX_LEN) {
            snake_x[snake_len] = tail_x;   /* отрастили хвост обратно */
            snake_y[snake_len] = tail_y;
            snake_len++;
        }
        score += 10;
        place_food();
    }
}

int main(void)
{
    srand((unsigned)time(NULL));   /* разный «случай» при каждом запуске */

    enable_raw_mode();             /* переключаем терминал в игровой режим */

    /* начальная змейка из 3 сегментов в центре, ползёт вправо */
    snake_len = 3;
    int cx = WIDTH / 2;
    int cy = HEIGHT / 2;
    snake_x[0] = cx;     snake_y[0] = cy;
    snake_x[1] = cx - 1; snake_y[1] = cy;
    snake_x[2] = cx - 2; snake_y[2] = cy;
    dir_x = 1;
    dir_y = 0;
    score = 0;
    game_over = 0;

    place_food();

    while (!game_over) {
        /* считываем все накопившиеся нажатия */
        int key;
        while ((key = read_key()) != -1) {
            if (key == 'w' || key == 'W') set_dir(0, -1);
            else if (key == 's' || key == 'S') set_dir(0, 1);
            else if (key == 'a' || key == 'A') set_dir(-1, 0);
            else if (key == 'd' || key == 'D') set_dir(1, 0);
            else if (key == 'q' || key == 'Q') game_over = 1;
        }

        if (game_over) {
            break;             /* нажали q */
        }

        update();
        draw();

        usleep(150000);        /* пауза 0,15 с между кадрами */
    }

    disable_raw_mode();        /* ОБЯЗАТЕЛЬНО вернуть терминал как было */

    printf("\nИгра окончена! Итоговый счёт: %d\n", score);
    return 0;
}
```

## Как это работает

Проследим один оборот игрового цикла, пока `game_over` равен 0:

1. **Ввод.** Внутренний `while` вытягивает из буфера все нажатые
   клавиши. WASD меняют `dir_x/dir_y` через `set_dir` (с защитой от
   разворота), `q` поднимает `game_over`. Нет нажатий — `read_key`
   сразу отдаёт `-1`, и мы не зависаем.
2. **Шаг.** `update` запоминает хвост, сдвигает тело по цепочке,
   двигает голову на `(dir_x, dir_y)`. Затем проверяет стену и
   тело — при ударе ставит `game_over` и выходит. Если голова на
   еде — отращивает хвост обратно, плюсует счёт и кладёт новую еду.
3. **Отрисовка.** `draw` чистит экран `\033[H\033[2J` и заново рисует
   рамку, еду `*`, голову `O`, тело `o` и строку счёта.
4. **Пауза.** `usleep(150000)` ждёт 0,15 секунды — иначе кадры
   мелькали бы слишком быстро, чтобы что-то разглядеть.

Цикл повторяется, и из быстрой смены кадров рождается плавное
движение. Как закончили — `disable_raw_mode` возвращает терминал в
нормальный вид, и печатается итоговый счёт.

Глобальные переменные (`snake_x`, `dir_x` и прочие) вынесены наружу,
чтобы все функции (`update`, `draw`, `place_food`) работали с одним и
тем же состоянием, не передавая кучу аргументов. Для маленькой игры в
один файл это нормально.

## Частые ошибки

**Забыл вернуть режим терминала.** Если программа завершится (или
упадёт) до `disable_raw_mode`, терминал останется в сыром режиме: ты
печатаешь, а букв не видно, Enter не срабатывает как обычно. Это не
поломка навсегда — набери вслепую команду `reset` и нажми Enter,
терминал починится. Чтобы такого не было, всегда зови
`disable_raw_mode` перед выходом.

**Картинка мерцает или «лесенкой» уезжает вниз.** Значит, ты не
очищаешь экран перед отрисовкой. Каждый кадр должен начинаться с
`printf("\033[H\033[2J")`. Если мерцание сильное, проверь, что не
печатаешь лишних пустых строк между кадрами.

**Выход за границу массива сегментов.** Если растить змейку без
проверки `if (snake_len < MAX_LEN)`, при заполнении всего поля длина
вылезет за размер массивов `snake_x/snake_y` — порча памяти. Граница
обязательна.

**Змейка мгновенно проигрывает при развороте.** Без защиты в
`set_dir` нажатие в обратную сторону вгоняет голову в свой второй
сегмент — и сразу «конец игры». Поэтому развороты на 180° запрещены.

**Цикл сдвига тела «съедает» змейку.** Если сдвигать сегменты от
головы к хвосту (а не от хвоста к голове), координаты затрутся раньше
времени, и тело схлопнется. Иди в цикле от `snake_len - 1` к `1`.

**`usleep` не компилируется при `-std=c11`.** Это и значит, что не
хватает `#define _DEFAULT_SOURCE` в самом начале файла (до
`#include`). Либо добавь его, либо собирай с `-D_DEFAULT_SOURCE`.

## Упражнения

1. **Ускорение.** Сделай так, чтобы с каждой съеденной едой игра шла
   быстрее: заведи переменную задержки (например, начать с `150000`) и
   уменьшай её на немного при росте, но не ниже какого-то минимума,
   чтобы змейка не стала неуправляемой. Передавай это значение в
   `usleep`.

2. **Пауза.** Добавь клавишу `p` — пауза. По нажатию игра замирает
   (цикл крутится, но `update` не вызывается и рисуется надпись
   «ПАУЗА»), повторное нажатие `p` продолжает.

3. **Стены-телепорты.** Сделай режим, где змейка не разбивается о
   стену, а появляется с противоположной стороны. Подсказка: вместо
   проверки на проигрыш заверни координаты по модулю — например,
   `snake_x[0] = (snake_x[0] + WIDTH) % WIDTH`.

4. **Рекорд.** Запоминай лучший счёт за сессию и показывай его рядом с
   текущим. Усложнение: сохраняй рекорд в файл (`fopen`, `fprintf`,
   `fscanf`) и читай при старте, чтобы он жил между запусками.

5. **Две еды.** Добавь второй вид еды, которая даёт больше очков, но
   живёт на поле ограниченное число кадров и потом исчезает.

6. **Размер поля.** Вынеси `WIDTH` и `HEIGHT` в аргументы командной
   строки (`int main(int argc, char *argv[])`), чтобы запускать
   `./snake 30 15`. Подумай, как тогда задать размеры массивов
   (подсказка: `malloc`).
