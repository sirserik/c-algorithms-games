# Глава 14. Игра «Виселица»

Угадал число — пора угадывать слова. «Виселица» (hangman) — это та
самая игра, где компьютер загадывает слово, показывает его пустыми
прочерками `_ _ _ _`, а ты называешь буквы по одной. Угадал букву —
она открывается во всех своих местах. Промахнулся — теряешь жизнь и к
виселице пририсовывается ещё одна часть тела. Открыл всё слово —
победа; кончились жизни — проигрыш.

Игра простая на вид, но в ней соберётся всё, что ты уже знаешь:
массив строк, случайный выбор, посимвольная работа со строкой, цикл,
ветвления, флаги. И добавится пара новых приёмов: тип `const char *`
(указатель на неизменяемую строку) и хитрый пробел в формате `scanf`,
который чистит ввод от лишних переводов строки.

## Что мы сделаем

Программу `code/14-hangman.c`, которая:

- держит список слов и выбирает одно случайно;
- показывает его как ряд прочерков, открывая угаданные буквы;
- читает букву с клавиатуры, приводит к нижнему регистру;
- проверяет, есть ли буква в слове; за промах снимает жизнь;
- рисует стадии виселицы ASCII-картинкой;
- объявляет победу, когда открыты все буквы, и поражение, когда
  кончились жизни.

Сразу важное предупреждение, как и в главе 10: мы считаем **символы**,
а в UTF-8 русская буква занимает 2 байта, латинская — 1. Поэтому слова
берём **английские** (латиница). Русский текст оставляем только для
сообщений — `printf` печатает байты как есть, и они выглядят верно.

## Разбираем задачу руками

Возьмём слово `apple`. Что происходит за одну партию?

```text
секрет:  a p p l e
экран:   _ _ _ _ _      (пять прочерков — по числу букв)

игрок называет 'p'  -> 'p' есть в слове, открываем ОБА p:
экран:   _ p p _ _

игрок называет 'z'  -> 'z' в слове нет: минус жизнь
игрок называет 'a'  -> открываем: a p p _ _
игрок называет 'l'  -> a p p l _
игрок называет 'e'  -> a p p l e   -> все буквы открыты -> ПОБЕДА
```

Что нам нужно хранить, чтобы это повторить машиной:

1. **само слово** (`secret`);
2. **какие буквы уже названы** — чтобы знать, что открывать и не
   засчитывать повтор;
3. **сколько ошибок** сделано — для жизней и для картинки виселицы.

Заведём под пункт 2 массив на 26 английских букв: `guessed['a'-'a']`,
`guessed['b'-'a']`, … По букве легко получить её номер: `c - 'a'`.
Помнишь из главы 2, что `char` — это маленькое целое (код символа)?
Значит `'c' - 'a'` равно 2, `'a' - 'a'` равно 0 — готовый индекс.

Дальше строим программу по кусочкам.

## Шаг 1. Список слов и случайный выбор

Слова — это набор строк. Удобнее всего хранить их так:

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <time.h>

int main(void)
{
    const char *words[] = {
        "apple", "banana", "orange", "computer", "program",
        "keyboard", "function", "pointer", "rainbow", "elephant"
    };
    int word_count = (int)(sizeof words / sizeof words[0]);

    srand((unsigned int)time(NULL));
    const char *secret = words[rand() % word_count];

    printf("Загадано слово из %zu букв.\n", strlen(secret));
    printf("(для проверки: %s)\n", secret);
    return 0;
}
```

Здесь новое — строка `const char *words[]`. Разберём её по косточкам,
это важный тип.

- Из главы 3 ты знаешь: строка `"apple"` живёт в памяти как массив
  символов, а её имя превращается в **адрес первого символа**. То есть
  каждый литерал в списке — это адрес строки.
- `const char *` — это «**указатель на символ**», то есть переменная,
  хранящая адрес начала строки. Слово `const` (константа) добавляет
  обещание: «через этот указатель я строку **менять не буду**».
  Строковые литералы в Си менять нельзя (попытка — это падение),
  поэтому `const` тут не каприз, а защита: компилятор не даст случайно
  написать в такую строку.
- `const char *words[]` — массив таких указателей. Получается список
  адресов: `words[0]` — адрес `"apple"`, `words[1]` — адрес
  `"banana"`, и так далее. Размер `[]` пустой — компилятор сам
  посчитает по числу элементов в фигурных скобках.

Дальше:

- `sizeof words / sizeof words[0]` — стандартный приём «сколько
  элементов в массиве». `sizeof words` — размер всего массива в байтах,
  `sizeof words[0]` — размер одного элемента (одного указателя). Их
  частное и есть число слов. Так не придётся вручную писать `10` и
  ошибаться при добавлении слов. Результат `sizeof` — беззнаковый тип
  `size_t`, поэтому приводим к `int` через `(int)`, чтобы не было
  предупреждений при сравнении со счётчиком.
- `srand((unsigned int)time(NULL));` — заводим генератор случайных
  чисел текущим временем (разобрали в главе про угадайку): без этого
  `rand()` каждый запуск выдавал бы одну и ту же «случайность».
- `words[rand() % word_count]` — `rand() % word_count` даёт случайный
  индекс от 0 до `word_count - 1`, по нему берём слово. Кладём его
  адрес в `const char *secret`.
- `%zu` — спецификатор для `size_t` (то, что возвращает `strlen`).
  Печатать `size_t` через обычный `%d` — неверный тип; для него есть
  отдельный `%zu`.

Строку `(для проверки: %s)` мы потом уберём — она просто показывает
загаданное слово, чтобы убедиться, что выбор работает.

```text
Загадано слово из 6 букв.
(для проверки: orange)
```

Слово выбирается, длину знаем. Едем дальше.

## Шаг 2. Показываем слово прочерками

Игрок не должен видеть слово — он видит ряд `_`. Напишем это отдельной
функцией: пройдём по символам и для каждого напечатаем либо саму
букву (если уже угадана), либо `_`.

Пока «угаданных» букв у нас нет, поэтому заведём массив-флаги
`guessed` на 26 букв и передадим его в функцию. Все нули — значит,
открытых букв нет, и функция нарисует одни прочерки.

```c
int draw_word(const char *word, const int *guessed)
{
    int revealed = 0;
    for (int i = 0; word[i] != '\0'; i++) {
        char ch = word[i];
        if (guessed[ch - 'a']) {
            printf("%c ", ch);
            revealed++;
        } else {
            printf("_ ");
        }
    }
    printf("\n");
    return revealed;
}
```

Разбор функции:

- `int draw_word(const char *word, const int *guessed)` — принимает
  слово (указатель на строку) и массив флагов. Массив в Си передаётся
  как указатель на первый элемент (глава 3), поэтому параметр —
  `const int *guessed`. `const` снова обещает «менять не буду» — рисуем
  по флагам, но не трогаем их.
- `for (int i = 0; word[i] != '\0'; i++)` — идём по строке, пока не
  упрёмся в метку конца `'\0'`. Это привычный по главе 10 способ
  перебрать строку, не зная заранее её длины.
- `char ch = word[i];` — текущий символ.
- `guessed[ch - 'a']` — флаг для этой буквы. `ch - 'a'` — номер буквы
  (0 для `a`, 25 для `z`). Если флаг ненулевой — букву уже называли,
  печатаем её через `%c` и пробел, и считаем открытой (`revealed++`).
- иначе печатаем `_` и пробел — буква спрятана.
- функция возвращает `revealed` — сколько букв открыто. Это нам
  пригодится для проверки победы: если открыто столько же, сколько всех
  букв, — слово отгадано.

### Мина под этой функцией

Выражение `guessed[ch - 'a']` верно ровно до тех пор, пока `ch` —
строчная латинская буква. Все наши слова такие, так что пока всё
хорошо. Но представь: через неделю ты добавляешь в список загадку из
двух слов — `"red apple"`. Дойдя до пробела, функция посчитает
`' ' - 'a'`, то есть **−65**, и полезет в `guessed[-65]` — за границу
массива, в чужую память. Программа не упадёт, ничего не сообщит,
просто начнёт вести себя странно: у меня она нарисовала пробел так,
будто эта «буква» уже угадана.

Выход за границу массива — самая коварная ошибка в Си (глава 3
предупреждала): она не падает, не ругается, просто тихо портит
поведение. Лечится одной проверкой в начале витка — вставим её сразу
после `char ch = word[i];`:

```c
        if (ch < 'a' || ch > 'z') {   /* не строчная латиница: */
            printf("%c ", ch);        /* показываем как есть,   */
            revealed++;               /* угадывать её не нужно  */
            continue;
        }
```

Логика простая: всё, что не буква от `a` до `z`, показываем открытым и
сразу засчитываем в `revealed`. Пробел (или дефис, или что там ещё
окажется в загадке) угадывать не нужно — он и так виден. А засчитать
его в `revealed` обязательно: иначе `revealed` никогда не дорос бы до
`len`, и слово с пробелом стало бы неугадываемым в принципе.

Четыре строчки, а закрывают сразу две дыры. Такие проверки удобно
ставить сразу, пока помнишь, откуда берётся индекс, — потом никто уже
не вспомнит, почему тут можно, а тут нельзя. Полный текст функции с
этой вставкой ты увидишь в итоговом листинге главы.

Проверим в `main` (заведём пустой `guessed` и нарисуем):

```c
int guessed[26] = {0};       /* все нули — ничего не открыто */
draw_word(secret, guessed);
```

`int guessed[26] = {0};` — массив из 26 целых, и `= {0}` заполняет
**весь** массив нулями (хватает одного нуля в фигурных скобках —
остальные элементы тоже станут нулями). Вывод для `orange`:

```text
_ _ _ _ _ _
```

Шесть прочерков. То, что нужно.

## Шаг 3. Читаем букву — и ловим коварный перевод строки

Теперь спросим у игрока букву. Букву читают через `%c` в `scanf`.
Напишем наивно:

```c
char c;
printf("Твоя буква: ");
scanf("%c", &c);
printf("Ты ввёл: [%c]\n", c);

printf("Ещё буква: ");
scanf("%c", &c);
printf("Ты ввёл: [%c]\n", c);
```

`%c` читает **ровно один символ** (в отличие от `%d`, который
пропускает пробелы и читает число). `&c` — адрес переменной, куда
записать символ (как в главе 2).

Запускаем, вводим `a`, жмём Enter, потом `b`, Enter:

```text
Твоя буква: a
Ты ввёл: [a]
Ещё буква: Ты ввёл: [
]
```

Что за ерунда? Второй раз мы и спросить толком не успели, а в `c`
оказался перевод строки. Вот в чём дело: когда ты набрал `a` и нажал
Enter, в буфер ввода попало **два** символа — сама буква `a` и
невидимый символ перевода строки `'\n'` (от Enter). Первый `scanf`
забрал `a`, а `'\n'` остался ждать. Второй `scanf("%c")` тут же
схватил этот `'\n'` — вот он и «ввёлся».

**Фикс — пробел перед `%c`:** `scanf(" %c", &c)`. Пробел в строке
формата означает «пропусти сначала любое количество пробельных
символов» — пробелы, табы и переводы строки. То есть он съест
застрявший `'\n'` (и любые лишние пробелы) и дойдёт до настоящей
буквы.

```c
char c;
printf("Твоя буква: ");
scanf(" %c", &c);          /* пробел перед %c чистит мусор */
```

Теперь оба ввода читаются как буквы. Запомни этот пробел — он спасает
почти всегда, когда читаешь символы по одному.

### Приводим к нижнему регистру

Игрок может ввести `A` или `a` — для нас это одна буква. Приведём
заглавную к строчной:

```c
if (c >= 'A' && c <= 'Z') {
    c = (char)(c - 'A' + 'a');
}
```

- `c >= 'A' && c <= 'Z'` — проверяем, что символ в диапазоне заглавных
  латинских букв. Сравнивать символы можно как числа — это и есть их
  коды.
- `c - 'A' + 'a'` — арифметика над кодами: вычли «начало заглавных»,
  прибавили «начало строчных» — получили ту же букву в нижнем регистре
  (`'B'` → `'b'`). Приведение `(char)` нужно, потому что в Си
  результат таких выражений имеет тип `int`, и без `(char)` компилятор
  с `-Wall -Wextra` выдаст предупреждение о сужении при записи обратно
  в `char`.

И отсечём всё, что не английская буква (цифры, знаки, кириллица):

```c
if (c < 'a' || c > 'z') {
    printf("Это не английская буква. Попробуй ещё.\n");
    continue;
}
```

`continue` — пропустить остаток текущего витка цикла и сразу перейти к
следующему (мы познакомились с ним в главе 12). То есть «плохой» ввод
не тратит жизнь, мы просто переспрашиваем.

Порядок проверок тут не случайный: **сначала** приводим регистр,
**потом** отсекаем не-буквы. Сделай наоборот — и заглавная `A` не
пройдёт фильтр `c >= 'a' && c <= 'z'`, потому что код `'A'` (65)
меньше кода `'a'` (97). Игрок ввёл нормальную букву, а программа его
не поняла.

### Проверим этот кусок отдельно

Не будем сразу вставлять всё в игру — соберём маленькую программку,
которая только читает буквы и говорит, что о них думает. Так проще
увидеть, как ведут себя края.

```c
#include <stdio.h>

int main(void)
{
    for (int i = 0; i < 4; i++) {
        char c;
        printf("Твоя буква: ");
        if (scanf(" %c", &c) != 1) {
            printf("\nВвод кончился.\n");
            return 0;
        }
        if (c >= 'A' && c <= 'Z') {
            c = (char)(c - 'A' + 'a');
        }
        if (c < 'a' || c > 'z') {
            printf("Это не английская буква. Попробуй ещё.\n");
            continue;
        }
        printf("Принято: '%c', номер в алфавите: %d\n", c, c - 'a');
    }
    return 0;
}
```

Скормим ей `5`, `B` и русскую `я`:

```text
Твоя буква: 5
Это не английская буква. Попробуй ещё.
Твоя буква: B
Принято: 'b', номер в алфавите: 1
Твоя буква: я
Это не английская буква. Попробуй ещё.
Твоя буква: Это не английская буква. Попробуй ещё.
```

Цифру отвергли, заглавную `B` превратили в `b` и посчитали номер 1 —
всё как задумано. А вот последние две строки стоит разобрать: ввели мы
**одну** русскую букву, а ругательство напечаталось **дважды**.

Причина — та самая UTF-8, о которой предупреждали в начале главы.
Русская `я` хранится как два байта, а `%c` читает по одному байту за
раз. Первый байт на латинскую букву не похож — «не английская буква».
Второй остаётся в буфере и на следующем витке читается сам собой, без
всякого набора с клавиатуры: отсюда и приглашение без ответа рядом, и
второе ругательство. Ломаться при этом нечему — оба байта аккуратно
отвергнуты, жизнь цела, индекс за границу не улетел. Просто игрок
получит два сообщения вместо одного, и теперь ты знаешь, откуда они.

## Шаг 4. Запоминаем букву и открываем её

Букву прочитали. Что с ней делать?

Сначала — не повторялась ли она:

```c
if (guessed[c - 'a']) {
    printf("Букву '%c' ты уже называл.\n", c);
    continue;
}
guessed[c - 'a'] = 1;        /* отмечаем букву как названную */
```

Если флаг уже стоит — буква была, переспрашиваем (тоже без штрафа).
Иначе ставим флаг в 1. С этого момента `draw_word` будет открывать эту
букву во всех её местах автоматически — ведь функция рисует по
флагам.

Теперь проверим, есть ли буква в слове:

```c
int found = 0;
for (int i = 0; i < len; i++) {
    if (secret[i] == c) {
        found = 1;
        break;
    }
}
```

- `found` — флаг «нашли». Заводим как 0.
- идём по слову; как только нашли совпадение, ставим `found = 1` и
  `break` — выходим из цикла досрочно, дальше искать незачем.
- `len` — длина слова, посчитаем один раз через `strlen` (см. ниже).

Реакция:

```c
if (found) {
    printf("Есть такая буква!\n");
} else {
    wrong++;
    printf("Мимо.\n");
}
```

Промах — `wrong++` (на одну ошибку больше). Попадание — ничего не
снимаем.

## Шаг 5. Жизни, победа и поражение

Соберём цикл партии. Ошибок разрешим, скажем, шесть — это и будет
число стадий виселицы. Заведём константу:

```c
#define MAX_WRONG 6
```

`#define` — это **директива препроцессора**: перед компиляцией
текст `MAX_WRONG` везде заменится на `6`. Удобно: захочешь сделать
игру легче — поменяешь число в одном месте. Имена таких констант
по традиции пишут заглавными.

Главный цикл крутится, пока ошибок меньше предела:

```c
int len = (int)strlen(secret);
int wrong = 0;

while (wrong < MAX_WRONG) {
    int revealed = draw_word(secret, guessed);
    if (revealed == len) {
        printf("Победа! Слово: %s\n", secret);
        return 0;
    }
    /* ... спросить букву, обработать (шаги 3-4) ... */
}

printf("Ты проиграл. Слово было: %s\n", secret);
```

Как это работает:

- сначала рисуем слово и узнаём `revealed` — сколько букв открыто;
- если открыто столько же, сколько всего (`revealed == len`), —
  слово отгадано, печатаем победу и `return 0` (выходим из программы);
- иначе спрашиваем букву и обрабатываем её;
- промахи копят `wrong`; как только `wrong` дорастёт до `MAX_WRONG`,
  условие `while` станет ложным, цикл закончится — и сработает строка
  про проигрыш.

Заметь порядок: победу проверяем **в начале** витка, после отрисовки.
Поэтому когда ты последней буквой открываешь всё слово, на следующем
витке `draw_word` покажет полное слово и тут же объявит победу.

## Шаг 6. Рисуем виселицу

Осталось украшение — ASCII-картинка, которая дорастает с каждой
ошибкой. Сделаем массив из семи строк: на 0 ошибок, на 1, …, на 6.
Индекс — число ошибок.

```c

    "  +---+\n  |   |\n  O   |\n  |   |\n      |\n      |\n=========",
    "  +---+\n  |   |\n  O   |\n /|   |\n      |\n      |\n=========",
    "  +---+\n  |   |\n  O   |\n /|\\  |\n      |\n      |\n=========",
    "  +---+\n  |   |\n  O   |\n /|\\  |\n /    |\n      |\n=========",
    "  +---+\n  |   |\n  O   |\n /|\\  |\n / \\  |\n      |\n========="
};
```

- это снова массив `const char *` — список строк, как наш список слов.
- `[MAX_WRONG + 1]` — нужно 7 ячеек: от 0 до 6 ошибок включительно.
- внутри строк `\n` — перевод строки: одна строковая константа
  рисует сразу несколько строк картинки.
- `\\` — это **один** символ обратной косой черты `\`. В строке `\`
  начинает спецсимвол (`\n`), поэтому сам бэкслеш записывают удвоенным
  — `\\`. Так рисуются руки и нога человечка.

Печатаем нужную стадию по числу ошибок: `printf("%s\n", gallows[wrong])`.
А при проигрыше показываем последнюю, полную: `gallows[MAX_WRONG]`.

Набирать такую картинку в исходнике неудобно, а ошибиться в пробелах

## Полная программа

`code/14-hangman.c`:

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <time.h>

#define MAX_WRONG 6   /* сколько ошибок позволяем до проигрыша */

/* Рисует слово: открытые буквы — как есть, закрытые — подчёркиванием.
   Возвращает, сколько букв уже открыто. */
int draw_word(const char *word, const int *guessed)
{
    int revealed = 0;
    for (int i = 0; word[i] != '\0'; i++) {
        char ch = word[i];
        if (ch < 'a' || ch > 'z') {   /* не строчная латиница: */
            printf("%c ", ch);        /* показываем как есть,   */
            revealed++;               /* угадывать её не нужно  */
            continue;
        }
        if (guessed[ch - 'a']) {
            printf("%c ", ch);
            revealed++;
        } else {
            printf("_ ");
        }
    }
    printf("\n");
    return revealed;
}

int main(void)
{
    const char *words[] = {
        "apple", "banana", "orange", "computer", "program",
        "keyboard", "function", "pointer", "rainbow", "elephant"
    };
    int word_count = (int)(sizeof words / sizeof words[0]);

    /* Стадии виселицы: индекс = число ошибок (0..MAX_WRONG). */
    const char *gallows[MAX_WRONG + 1] = {
        "  +---+\n  |   |\n      |\n      |\n      |\n      |\n=========",
        "  +---+\n  |   |\n  O   |\n      |\n      |\n      |\n=========",
        "  +---+\n  |   |\n  O   |\n  |   |\n      |\n      |\n=========",
        "  +---+\n  |   |\n  O   |\n /|   |\n      |\n      |\n=========",
        "  +---+\n  |   |\n  O   |\n /|\\  |\n      |\n      |\n=========",
        "  +---+\n  |   |\n  O   |\n /|\\  |\n /    |\n      |\n=========",
        "  +---+\n  |   |\n  O   |\n /|\\  |\n / \\  |\n      |\n========="
    };

    srand((unsigned int)time(NULL));

    const char *secret = words[rand() % word_count];
    int len = (int)strlen(secret);

    /* guessed[c - 'a'] == 1, если букву уже называли */
    int guessed[26] = {0};
    int wrong = 0;

    printf("Игра \"Виселица\". Угадай слово по буквам!\n");

    while (wrong < MAX_WRONG) {
        printf("\n%s\n\n", gallows[wrong]);

        int revealed = draw_word(secret, guessed);
        if (revealed == len) {
            printf("Победа! Слово: %s\n", secret);
            return 0;
        }

        printf("Ошибок: %d из %d\n", wrong, MAX_WRONG);
        printf("Твоя буква: ");

        char c;
        if (scanf(" %c", &c) != 1) {
            /* ввод кончился (Ctrl+D) — это не проигрыш, а выход */
            printf("\nИгра прервана. Слово было: %s\n", secret);
            return 0;
        }

        if (c >= 'A' && c <= 'Z') {
            c = (char)(c - 'A' + 'a');   /* в нижний регистр */
        }
        if (c < 'a' || c > 'z') {
            printf("Это не английская буква. Попробуй ещё.\n");
            continue;
        }
        if (guessed[c - 'a']) {
            printf("Букву '%c' ты уже называл.\n", c);
            continue;
        }
        guessed[c - 'a'] = 1;

        int found = 0;
        for (int i = 0; i < len; i++) {
            if (secret[i] == c) {
                found = 1;
                break;
            }
        }
        if (found) {
            printf("Есть такая буква!\n");
        } else {
            wrong++;
            printf("Мимо.\n");
        }
    }

    printf("\n%s\n\n", gallows[MAX_WRONG]);
    printf("Ты проиграл. Слово было: %s\n", secret);
    return 0;
}
```

Пара мест, которые мы ещё не отметили:

- `if (scanf(" %c", &c) != 1) { ... }` — `scanf` возвращает, сколько
  значений он успешно прочитал. Здесь ждём одно. Если вернулось не 1 —
  ввод кончился (нажали Ctrl+D или скормили файл, который закончился).
  Проверять результат `scanf` — хорошая привычка, мы завели её в
  главе 12.

  Внутри — `return 0`, а не `break`, и вот почему. Цикл заканчивается
  ровно в одном случае: игрок исчерпал все шесть ошибок. Поэтому
  сразу за циклом стоит «Ты проиграл» с полной виселицей. Если по
  Ctrl+D мы просто выйдем из цикла через `break`, программа объявит
  проигрыш человеку, у которого могло быть пять открытых букв и ни
  одной ошибки, и дорисует ему петлю. Это враньё. Прерванная игра —
  не проигрыш, поэтому выходим отдельным путём и говорим об этом
  честно.
- `printf("Игра \"Виселица\"...")` — внутри строки кавычку
  экранируют через `\"`, иначе компилятор решит, что строка тут и
  закончилась.

## Как это работает

Один виток главного цикла:

1. печатаем виселицу по числу ошибок: `gallows[wrong]`;
2. рисуем слово прочерками и узнаём, сколько букв открыто;
3. если открыты все — победа, выходим;
4. показываем счётчик ошибок и просим букву;
5. читаем символ (`" %c"` чистит лишний `'\n'`), приводим к нижнему
   регистру, отсекаем не-буквы и повторы;
6. ищем букву в слове: попала — радуемся, промах — `wrong++`;
7. возвращаемся к шагу 1.

Когда `wrong` дорастает до `MAX_WRONG`, цикл заканчивается, и печатается
проигрыш. Когда `revealed == len` — победа в шаге 3. Массив `guessed`
связывает всё вместе: достаточно поставить один флаг, и буква сама
«проявляется» при следующей отрисовке во всех своих позициях.

## Частые ошибки

**`scanf("%c")` без пробела.** Главная ловушка главы. После ввода в
буфере остаётся `'\n'` от Enter, и следующий `%c` читает его вместо
буквы. Лечится пробелом: `scanf(" %c", &c)`. Для `%d` и `%s` пробел не
нужен — они сами пропускают пробельные символы, а вот `%c` — нет.

**Забыл привести регистр.** Если не переводить `A` в `a`, то заглавная
буква не совпадёт ни с одной строчной буквой слова, и игрок будет
честно угадывать, но «промахиваться». Приводи ввод к нижнему регистру.

**Повторная буква снимает жизнь.** Если не проверять `guessed` до
поиска, игрок назовёт ту же неудачную букву дважды и потеряет две
жизни за одну ошибку (или будет бесконечно «угадывать» уже открытую).
Проверка `if (guessed[c - 'a']) continue;` это закрывает.

**Индекс за границей `guessed`.** `guessed[c - 'a']` верен только для
`c` от `'a'` до `'z'`. Если сначала не отсечь не-буквы, то, скажем,
цифра `'5'` даст `'5' - 'a'` — отрицательный индекс и выход за границы
массива (глава 3 предупреждала, чем это грозит). Поэтому проверку
диапазона делаем **до** обращения к `guessed` — и во вводе, и внутри
`draw_word`. Опаснее всего то, что такой промах **не падает**:
программа читает чужой байт, принимает его за флаг и просто начинает
врать. Ни компилятор, ни запуск ничего не скажут.

**Порядок «регистр — потом фильтр».** Приводить `A` к `a` надо
**раньше**, чем отсекать не-буквы. Поменяешь местами — и заглавные
буквы отвалятся на фильтре, потому что код `'A'` (65) меньше кода
`'a'` (97).

**Русская буква даёт два сообщения.** Не баг, а следствие UTF-8: одна
кириллическая буква — два байта, `%c` читает по байту, значит,
«Это не английская буква» напечатается дважды. Жизнь при этом не
теряется, ломаться нечему. Просто знай, откуда лишняя строка.

**Победу проверяем не там.** Если сверять `revealed == len` только
после ввода буквы, а не в начале витка, легко получить лишний запрос
буквы уже у отгаданного слова. Рисуем — проверяем — потом спрашиваем.

**Несколько букв в одной строке.** Наберёшь `abc` и нажмёшь Enter —
программа не ругнётся, а разберёт это как три отдельных хода: `a`,
потом `b`, потом `c`. Так работает `" %c"`, он читает по одному
символу и не требует Enter между ними. Иногда удобно, иногда
неожиданно — теперь ты предупреждён.

## Упражнения

1. Добавь подсчёт **открытых букв** в подсказке: печатай не только
   «Ошибок: 2 из 6», но и «Открыто: 3 из 5».
2. Показывай игроку, какие буквы он уже называл (пройди по `guessed` и
   напечатай все буквы с флагом 1). Это убережёт от повторов.
3. Сделай уровни сложности: спроси перед игрой число жизней (например,
   от 4 до 8) и используй его вместо `MAX_WRONG`. Не забудь, что число
   стадий виселицы должно совпадать с числом жизней.
4. Добавь в список загадку из двух слов — например `"red apple"` — и
   сыграй партию. Благодаря проверке `ch < 'a' || ch > 'z'` в
   `draw_word` пробел рисуется как пробел и сразу считается открытым,
   так что игра должна пройти нормально. Убери эту проверку, запусти
   ещё раз и посмотри, как программа начнёт врать: это и есть выход за
   границу массива в живом виде.
5. После партии спроси «Сыграем ещё? (y/n)» и, если `y`, начни заново
   (вынеси одну партию в функцию `int play_round(void)` и вызывай её в
   цикле в `main`).
6. Подсчёт очков: за победу начисляй очки, зависящие от числа
   оставшихся жизней, и веди счёт между партиями.

Главный новый навык — **состояние игры в нескольких переменных**
(слово, флаги, счётчик ошибок) и цикл, который это состояние двигает.
А ещё мы поймали в собственной функции мину замедленного действия:
индекс `ch - 'a'`, который вылетает за границу массива на первом же
слове с пробелом. Привыкай смотреть на каждый индекс и спрашивать
себя: «а откуда я знаю, что он попадёт в массив?»

В следующей главе шагнём в сторону игрового **поля**: напишем
«Крестики-нолики» с двумерным массивом, вложенными циклами и проверкой
восьми выигрышных линий. Играть будут двое за одним компьютером, а
простой бот останется тебе на упражнения.
